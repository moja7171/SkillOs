## مرتب‌سازی ساده

```python
numbers = [5, 2, 8, 1, 9]

numbers.sort()
print(numbers)
# [1, 2, 5, 8, 9]
```

`sort()` لیست رو **همون‌جا** (in-place) مرتب می‌کنه — چیزی برنمی‌گردونه، خود `numbers` تغییر می‌کنه.

## نزولی مرتب کن

```python
numbers.sort(reverse=True)
print(numbers)
# [9, 8, 5, 2, 1]
```

## `sorted()`: بدون دست‌زدن به لیست اصلی

اگه نمی‌خوای لیست اصلی تغییر کنه، از تابع آماده‌ی `sorted()` استفاده کن:

```python
numbers = [5, 2, 8, 1, 9]

new_list = sorted(numbers)
print(new_list)    # [1, 2, 5, 8, 9]
print(numbers)      # [5, 2, 8, 1, 9]  -- unchanged
```

`sorted()` هر پیمایش‌پذیری رو می‌گیره و یه **لیست جدید و مرتب‌شده** برمی‌گردونه؛ `sort()` فقط روی خود لیست کار می‌کنه و آدرس همون لیست رو تغییر می‌ده.

## مرتب‌سازی چیزهای پیچیده‌تر

فرض کن یه لیست از سفارش‌ها داری — هر سفارش یه تاپل `(اسم محصول، قیمت)`:

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]

items.sort()
print(items)
```

با `sort()` ساده، هیچی درست مرتب نمی‌شه — پایتون نمی‌دونه بر چه اساسی این تاپل‌ها رو مقایسه کنه. باید بهش بگی: «بر اساس چی مرتب کن».

## پارامتر `key`

```python
def sort_item(item):
    return item[1]

items.sort(key=sort_item)
print(items)
```

`sort()` یه پارامتر به اسم `key` داره — یه تابع که به هر عضو اعمال می‌شه و مقداری که ازش برمی‌گرده، معیار مرتب‌سازی می‌شه. اینجا `sort_item` قیمت هر سفارش رو برمی‌گردونه، پس لیست بر اساس قیمت مرتب می‌شه.

> نکته: اینجا `sort_item` رو **صدا نمی‌زنیم** (بدون پرانتز) — فقط یه اشاره به خود تابع بهش می‌دیم. خود `sort()` هرجا لازم باشه صداش می‌زنه.

> نکته‌ی دیگه: `sort()` آرگومان‌هاش رو فقط به‌صورت کلیدی قبول می‌کنه — یعنی حتماً باید بنویسی `key=...`، نه فقط `sort(sort_item)`.
