## ساخت مستندات از روی docstring

توی درس قبل یاد گرفتیم چطور کد رو با docstring مستند کنیم. حالا سؤال اینه: چطور این مستندات رو **ببینیم**، بدون اینکه خودمون بریم توی کد رو بخونیم؟ پایتون یه ابزار خط‌فرمان آماده به اسم `pydoc` داره که دقیقاً همین کار رو می‌کنه — چه برای ماژول‌های کتابخانه‌ی استاندارد، چه برای ماژول‌های خودمون.

## دیدن مستندات یه ماژول توی ترمینال

```bash
pydoc3 math
```

این دستور مستندات کامل ماژول `math` (شامل همه‌ی توابعش و توضیحاتشون) رو مستقیم توی ترمینال نشون می‌ده. اگه مستندات طولانی‌تر از یه صفحه باشه، با کلید `space` صفحه‌ی بعد رو می‌بینی و با `q` از این حالت خارج می‌شی.

همین‌طور می‌شه مستندات ماژول‌های خودمون رو دید:

```bash
pydoc3 mypdf.pdf_to_text
```

## خروجی HTML

با سوییچ `-w`، به‌جای نمایش توی ترمینال، یه فایل HTML از مستندات می‌سازه:

```bash
pydoc3 -w mypdf.pdf_to_text
```

## یه سرور محلی برای مرور مستندات

جالب‌ترین قابلیتش، بالا آوردن یه سرور وبه که هم مستندات پروژه‌ی خودت، هم مستندات کتابخانه‌ی استاندارد پایتون رو یک‌جا، با لینک‌های قابل‌کلیک، نشون می‌ده:

```bash
pydoc3 -p 1234
```

با باز کردن `localhost:1234` توی مرورگر، می‌شه بین ماژول‌های پروژه‌ی خودت و ماژول‌های کتابخانه‌ی استاندارد (مثل `pathlib`) گشت — حتی رابطه‌ی وراثت بین کلاس‌ها (مثلاً `PosixPath` که از `PurePath` ارث می‌بره، و اون از `object`) هم قابل‌مشاهده‌ست.

## جمع‌بندی

هرچی بیشتر و دقیق‌تر با docstring مستندسازی کنی، خروجی `pydoc` هم کامل‌تر می‌شه — این ابزار خودش هیچ اطلاعات جدیدی تولید نمی‌کنه، فقط همون docstringهایی که نوشتی رو به‌شکل خوانا (ترمینال، HTML، یا یه سایت محلی) نمایش می‌ده.
