## یه راه تمیزتر برای نوشتن if/else

فرض کن داری برای یه دانشگاه بررسی می‌کنی که یه متقاضی واجد شرایطه یا نه:

```python
age = 22

if age >= 18:
    message = "Eligible"
else:
    message = "Not eligible"

print(message)
```

هیچ ایرادی توی این کد نیست، ولی وقتی تنها کاری که داری می‌کنی اینه که بر اساس یه شرط، یه مقدار به یه متغیر بدی، می‌تونی خیلی تمیزتر بنویسیش:

```python
age = 22

message = "Eligible" if age >= 18 else "Not eligible"

print(message)
```

این یه خط دقیقاً معادل همون چهار خط بالاست. به این می‌گیم **عملگر شرطی سه‌گانه** (ternary operator).

## چطور می‌خونیمش

ترتیب خوندنش تقریباً مثل زبان محاوره‌ست:

```python
message = "Eligible" if age >= 18 else "Not eligible"
```

می‌تونی سه بخشش رو این‌طوری از هم جدا کنی: اول مقداری که اگه شرط `True` باشه می‌گیریم (`"Eligible"`)، وسط خود شرط (`age >= 18`)، و آخر مقداری که اگه شرط `False` باشه می‌گیریم (`"Not eligible"`). یعنی: «`message` رو بذار `"Eligible"`، اگه `age >= 18`، وگرنه بذار `"Not eligible"`.»

اگه `age` رو بذاری `12`، این‌بار شرط `False` می‌شه، پس `message` مقدار `"Not eligible"` رو می‌گیره.

## کِی از ternary استفاده کنیم

فقط وقتی که ساختار if/else داری این شکلیه: هر دو شاخه فقط دارن یه مقدار به یه متغیر می‌دن (یا مستقیم return/print می‌کنن). اگه توی هر شاخه چند تا کار مختلف انجام می‌شه، همون if/else معمولی رو نگه دار — ternary قرار نیست همه‌جا جای if/else رو بگیره، فقط برای همین حالت خاص خوانایی رو بهتر می‌کنه.
