## ویژگی‌های نمونه (Instance Attributes)

`x` و `y` که توی سازنده‌ی `Point` تعریف کردیم، مثال‌هایی از **ویژگی نمونه** (instance attribute) هستن — یعنی متعلق به یه آبجکت خاصن، نه کل کلاس. هر آبجکت مقدار خودش رو داره:

```python
point1 = Point(1, 2)
point2 = Point(10, 20)

print(point1.x, point2.x)
# 1 10
```

`point1` و `point2` کاملاً از هم مستقلن — تغییردادن یکی، اون یکی رو تحت‌تاثیر قرار نمی‌ده.

## می‌شه بعداً هم ویژگی اضافه کرد

آبجکت‌های پایتون **پویا**ن — لازم نیست همه‌ی ویژگی‌ها حتماً توی سازنده تعریف بشن:

```python
point1.z = 10
```

این خط یه ویژگی جدید (`z`) به `point1` اضافه می‌کنه — بدون اینکه سازنده رو تغییر بدیم.

## ویژگی‌های کلاس (Class Attributes)

در مقابل ویژگی نمونه، **ویژگی کلاس** (class attribute) یه مقداره که مستقیم توی بدنه‌ی کلاس (نه توی `__init__`) تعریف می‌شه، و بین **همه‌ی** آبجکت‌های اون کلاس مشترکه:

```python
class Point:
    default_color = "red"

    def __init__(self, x, y):
        self.x = x
        self.y = y
```

## دسترسی به ویژگی کلاس

هم از طریق خود کلاس، هم از طریق هر آبجکتی که ازش ساختی، بهش دسترسی داری:

```python
point = Point(1, 2)

print(point.default_color)   # red
print(Point.default_color)   # red
```

## تغییردادنش روی همه اثر می‌ذاره

```python
Point.default_color = "yellow"

another = Point(3, 4)
print(point.default_color)      # yellow
print(another.default_color)    # yellow
```

چون `default_color` سطح کلاسه (نه نمونه)، تغییردادنش از طریق **خود کلاس**، روی **همه‌ی آبجکت‌ها** — چه قدیمی چه جدید — اثر می‌ذاره.

## کدوم رو استفاده کنیم؟

توی عمل، بیشتر وقت‌ها از ویژگی نمونه استفاده می‌کنی — هر آبجکت مقادیر خودش رو داره. ویژگی کلاس رو فقط جایی به‌کار ببر که واقعاً یه مقدار باید بین **همه‌ی** نمونه‌های یه کلاس مشترک باشه.
