## Project چیه و چه فرقی با یه چت معمولی داره

از پنل چپ ChatGPT، گزینه‌ی «New Project» یه فضای کاری جدا می‌سازه که چت‌ها، فایل‌ها، و دستورالعمل‌های سفارشی رو **یک‌جا** نگه می‌داره — برای کارهای مداوم و بلندمدت، نه یه سؤال یک‌باره.

فکرش کن مثل یه پوشه‌ی اختصاصی برای یه پروژه‌ی واقعی: اگه اسکرام مستر یه پروژه‌ی خاص (مثلاً همون اپ فروشگاهی Sintra که توی این دوره باهاش کار کردیم) هستی، یه Project به‌اسم همون پروژه می‌سازی، و از اون به بعد هر فایل و هر گفت‌وگوی مرتبط باهاش همون‌جا جمع می‌شه.

## مزیت اصلی: دیگه لازم نیست هر بار فایل پیوست کنی

توی یه Project، فایل‌هایی که آپلود می‌کنی (مثلاً بک‌لاگ اسپرینت) توی یه «مخزن» (repository) دائمی ذخیره می‌شن — همه‌ی گفت‌وگوهای جدیدی که داخل همون Project می‌سازی، به این فایل‌ها دسترسی دارن، **بدون این‌که هر بار دوباره پیوستشون کنی**. مثلاً می‌تونی توی یه thread تازه بپرسی «کدوم یوزر استوری‌ها هنوز شروع نشدن؟» و ChatGPT خودش می‌ره سراغ فایل بک‌لاگی که قبلاً توی همون Project آپلود کردی.

این با حافظه‌ی مکالمه‌ای (که فقط داخل یه thread کار می‌کرد) فرق اساسی داره — این‌جا دسترسی به فایل‌ها در سطح **کل Project**ه، نه فقط یه گفت‌وگوی خاص.

## شخصی‌سازی مخصوص یه Project

همون‌طور که persistent memory رو برای کل حسابت تنظیم می‌کنی، می‌تونی برای هر Project هم دستورالعمل مخصوص همون پروژه بسازی — مثلاً «این پروژه برای توسعه‌ی اپ موبایل Sintra ئه؛ جواب‌ها رو مختصر، حرفه‌ای و ساخت‌یافته بده.» این دستورالعمل فقط روی همین Project اثر می‌ذاره، نه بقیه‌ی گفت‌وگوهات — برخلاف persistent memory سراسری که روی همه‌جا اثر می‌ذاره.

> جمع‌بندی: اگه با یه پروژه یا تیم خاص به‌طور مداوم کار می‌کنی، یه Project اختصاصی بساز — فایل‌های مرجع رو یه‌بار آپلود کن، دستورالعمل مخصوص همون پروژه رو تنظیم کن، و از اون به بعد هر گفت‌وگوی جدید داخل همون Project، بدون تکرار پیوست فایل، مستقیم به زمینه‌ی کامل پروژه دسترسی داره.
