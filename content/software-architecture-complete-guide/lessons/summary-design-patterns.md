## جمع‌بندی

توی این بخش، درباره‌ی الگوهای طراحی حرف زدیم. چهار الگو رو بررسی کردیم: Factory، Repository، Facade و Command. این الگوها، وقتی درست پیاده بشن، کمکت می‌کنن نرم‌افزاری طراحی کنی که سازگارتر، منعطف‌تر، خواناتر و راحت‌تر برای نگهداریه.

از طرف دیگه، برای پیاده‌کردنِ همه‌ی الگوهای موجود عجله نکن. یکی از اشتباهاتی که معمارهای جونیور اغلب می‌کنن، طراحیِ یه معماریِ الگومحوره — معماری‌ای که سعی می‌کنه هرچه بیشتر الگو پیاده کنه، به‌جای ساده نگه‌داشتنِ کارها. پس این کار رو هم نکن — فقط از الگوهایی استفاده کن که واقعاً بهشون نیاز داری.

توصیه می‌شه بیشتر درباره‌ی الگوهای طراحیِ مختلف مطالعه کنی — کتاب Gang of Four که قبلاً اشاره کردیم، نقطه‌ی شروع خوبیه. امیدواریم این بخش کمکت کرده باشه اصول پایه‌ی الگوهای طراحی رو بفهمی و ارزش واقعیشون رو توی کارت پیدا کنی.
