## ساختارهای داده‌ی درونی پایتون

از این بخش به بعد، با ساختارهای داده‌ی آماده‌ی پایتون آشنا می‌شیم: لیست، تاپل، مجموعه (set) و دیکشنری. شروع می‌کنیم با **لیست** (list).

## ساخت لیست

قبلاً دیدی که با کروشه می‌شه یه لیست ساخت:

```python
letters = ["a", "b", "c"]
numbers = [1, 2, 3]
matrix = [[1, 2], [3, 4]]
```

داخل یه لیست می‌تونی هر نوع مقداری بذاری — حتی لیست‌های دیگه. `matrix` بالا یه لیست دوبعدیه: هر عضوش خودش یه لیست دیگه‌ست.

## چندتا ترفند برای ساخت لیست

اگه بخوای یه لیست با ۱۰۰ تا صفر بسازی، لازم نیست دستی بنویسیش — یه لیست رو می‌شه با `*` تکرار کرد:

```python
zeros = [0] * 100
```

با `+` هم می‌شه دو تا لیست رو به هم وصل کرد:

```python
combined = [0] * 5 + ["a", "b", "c"]
print(combined)
# [0, 0, 0, 0, 0, 'a', 'b', 'c']
```

همون‌طور که می‌بینی، اعضای یه لیست لازم نیست همه‌شون یه نوع باشن.

## تبدیل هر پیمایش‌پذیری به لیست

تابع `list()` هر پیمایش‌پذیری (iterable) رو می‌گیره و به لیست تبدیل می‌کنه:

```python
numbers = list(range(5))
print(numbers)
# [0, 1, 2, 3, 4]

chars = list("hello")
print(chars)
# ['h', 'e', 'l', 'l', 'o']
```

چون `range` و رشته هر دو پیمایش‌پذیرن، می‌شه مستقیم بهشون `list()` رو اعمال کرد.

## طول یه لیست

با `len()` می‌شه تعداد اعضای یه لیست رو گرفت — دقیقاً مثل رشته‌ها:

```python
print(len(chars))
# 5
```
