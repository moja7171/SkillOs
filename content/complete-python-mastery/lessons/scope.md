## دامنه یعنی چی؟

**دامنه** (scope) یعنی بازه‌ای از کد که یه متغیر توش «وجود داره» و قابل‌دیدنه. بیا با یه مثال ببینیم:

```python
def greet(name):
    message = f"Hi {name}"
    print(message)


greet("Mosh")
print(message)
```

خط آخر با خطا مواجه می‌شه:
```
NameError: name 'message' is not defined
```

چرا؟ چون `message` و `name` **متغیرهای محلی** (local) هستن — فقط داخل تابع `greet` وجود دارن. بیرون از اون تابع، پایتون اصلاً نمی‌دونه `message` چیه.

## متغیرهای محلی در توابع مختلف، کاملاً جدان

```python
def greet(name):
    message = f"Hi {name}"


def send_email(name):
    message = f"Dear {name}"
```

با اینکه هر دو تابع یه متغیر به اسم `message` دارن، این دوتا **کاملاً بی‌ربط به همدیگه‌ن**. هرکدوم فقط توی همون تابع خودش معنا داره. متغیرهای محلی عمر کوتاهی دارن: وقتی تابع تموم می‌شه، پایتون حافظه‌شون رو آزاد می‌کنه.

## متغیرهای سراسری (Global)

اگه یه متغیر رو **بیرون از هر تابعی** تعریف کنی، می‌شه یه **متغیر سراسری** (global) — یعنی توی کل فایل، از هر جایی (داخل هر تابعی یا بیرون) قابل‌دسترسیه:

```python
message = "A"

def greet():
    print(message)   # can read the global


greet()
# A
```

## چرا نباید داخل تابع، متغیر سراسری رو عوض کنی

```python
message = "A"

def greet():
    message = "B"   # creates a new local variable!


greet()
print(message)
# A  -- not B!
```

عجیبه، نه؟ با اینکه اسمش با متغیر سراسری یکیه، پایتون به‌طور پیش‌فرض `message` داخل تابع رو یه **متغیر محلی جدید** در نظر می‌گیره، نه همون سراسری. برای همین متغیر سراسری اصلاً تغییر نکرد.

یه راه هست که واقعاً متغیر سراسری رو از داخل تابع تغییر بدی — با کلیدواژه‌ی `global`:

```python
message = "A"

def greet():
    global message
    message = "B"


greet()
print(message)
# B
```

## ولی این کار بد ه

با اینکه از نظر فنی کار می‌کنه، **تغییردادن متغیر سراسری از داخل یه تابع، یه عادت بده** که باید ازش دوری کنی. چرا؟ چون ممکنه چندین تابع مختلف به یه متغیر سراسری وابسته باشن؛ اگه یه تابع (عمداً یا سهواً) مقدارش رو عوض کنه، ممکنه رفتار توابع دیگه هم بدون اینکه انتظارش رو داشته باشی خراب بشه — یه باگ سخت برای پیداکردن.

**قاعده‌ی کلی:** تا جای ممکن به‌جای متغیر سراسری، از پارامتر و متغیر محلی استفاده کن. متغیر سراسری گاهی لازمه، ولی هیچ‌وقت از داخل یه تابع تغییرش نده.
