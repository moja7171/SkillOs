## float چیست؟

نوع پیش‌فرض پایتون برای اعداد حقیقی (`a = 10.5`). در CPython با `double` زبان C پیاده شده — استاندارد **IEEE 754 double precision** («binary64»). برخلاف int، **عرض ثابت** دارد: ۸ بایت = ۶۴ بیت (به‌علاوه‌ی سربار شیء: `sys.getsizeof(10.5)` → ۲۴ بایت، مستقل از مقدار).

آن ۶۴ بیت این‌طور تقسیم می‌شود:

| بخش | بیت | نقش |
|---|---|---|
| علامت | ۱ | ۰ مثبت، ۱ منفی |
| نما (exponent) | ۱۱ | توان؛ بازه‌ی −۱۰۲۲ تا ۱۰۲۳ |
| ارقام معنادار | ۵۲ | حدود **۱۵ تا ۱۷ رقم ده‌دهی** معنادار |

`1.5e-5` یعنی `1.5 × 10⁻⁵`؛ آن `−5` نماست. «رقم معنادار» ساده‌انگارانه یعنی ارقام بدون صفرهای ابتدا و انتها: `1.2345`، `12345`، `12345000000` و `0.00012345` همه **۵** رقم معنادار دارند — صفرها به نما می‌روند.

## نمایش ده‌دهی: مجموع ارقام × توان ۱۰

```
0.75    = 7×10⁻¹ + 5×10⁻²
123.456 = 1×10² + 2×10¹ + 3×10⁰ + 4×10⁻¹ + 5×10⁻² + 6×10⁻³
```

فرم کلی: `(−1)^sign × Σ dᵢ × 10ⁱ` با `dᵢ ∈ {0..9}`. بعضی اعداد جمع **متناهی** ندارند: نه فقط π و √2، بلکه `1/3 = 0.333…` هم. هر جا متوقف شوی، تقریب داری.

## نمایش دودویی: همان ایده با توان ۲

کامپیوتر فقط بیت دارد، پس ارقام `0` یا `1` و توان‌ها توان ۲:

```
0.11₂   = 1/2 + 1/4          = 0.75
0.1101₂ = 1/2 + 1/4 + 0 + 1/16 = 0.8125
```

و اینجا مشکل جدیدی ظاهر می‌شود: عددی که در ده‌دهی متناهی است، در دودویی می‌تواند **نامتناهی** باشد. `0.1` (یک‌دهم) در دودویی:

```
0.0 0011 0011 0011 …₂   (0011 تا ابد تکرار می‌شود)
= 1/16 + 1/32 + 1/256 + 1/512 + …
= 0.0625 → 0.09375 → 0.09765625 → …
```

هر جا ببری، تقریب است — گاهی کمی کمتر از ۰٫۱، گاهی کمی بیشتر.

## نتیجه: دقیق یا تقریبی

- **نمایش دودویی متناهی** → float **دقیق**: `0.125 = 1/8 = 0.001₂`، `0.75`، `0.8125`. اعدادی که مخرجشان توان ۲ است.
- **نمایش دودویی نامتناهی** → float **تقریبی**: `0.1`، `0.3`، `0.2`…

این نقص پایتون نیست؛ هر زبانی که float دودویی دارد همین است.

```python
format(0.1, '.15f')     # '0.100000000000000'   ← هنوز خوب به نظر می‌رسد
format(0.1, '.25f')     # '0.1000000000000000055511151'
format(0.125, '.25f')   # '0.1250000000000000000000000'   ← دقیق

float("22/7")           # ValueError — برخلاف Fraction
float(Fraction(22, 7))  # 3.142857142857143

a = 0.1 + 0.1 + 0.1
b = 0.3
a == b                  # False!
format(a, '.25f')       # '0.3000000000000000444089210'
format(b, '.25f')       # '0.2999999999999999888977698'
```

`print` نمایش را گرد می‌کند و این تفاوت‌ها را پنهان می‌کند. درس بعد: پس چطور float‌ها را مقایسه کنیم.
