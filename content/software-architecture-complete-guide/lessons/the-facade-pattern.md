## الگوی Facade

الگوی Facade یکی از ساده‌ترین الگوهاست، ولی همچنان یکی از مهم‌ترین‌ها. توی این الگو، یه لایه‌ی انتزاعی ساخته می‌شه که اکشن‌های پیچیده‌ی زیرینش رو پنهان می‌کنه و به کلاینت کمک می‌کنه اون اکشن رو راحت‌تر انجام بده.

### یه مثال

فرض کن یه سیستم بانکداری داریم. طبیعتاً باید یه راه برای انتقال پول بین حساب‌ها داشته باشیم. توسعه‌دهنده‌ها فرایندِ انتقال رو تحلیل می‌کنن و به یه لیست از اکشن‌هایی می‌رسن که باید انجام بشه:

۱. مطمئن بشن حساب‌های شرکت‌کننده توی انتقال واقعاً وجود دارن.
۲. مطمئن بشن پول کافی توی حساب اول برای انجام انتقال هست.
۳. پول رو از حساب اول برداشت کنن.
۴. پول رو توی حساب دوم واریز کنن.
۵. یه رویداد توی لاگِ حساب‌ها اضافه کنن که این انتقال رو برای هر دو حساب مستند می‌کنه.

توسعه‌دهنده‌ها، که آدم‌های وسواسی‌ای هستن، این پنج اکشن رو به‌شکل پنج متد جدا توی کد پیاده می‌کنن — که خوبه، چون هر کدوم از این اکشن‌ها می‌تونن مستقل هم استفاده بشن. مثلاً شاید لازم باشه موجودیِ یه حساب رو حتی بدون انتقالِ پول بررسی کنیم.

ولی نتیجه‌ش اینه که اگه یه کلاینت الان بخواد پول انتقال بده، باید به پنج متد دسترسی داشته باشه. یه فرایند طولانی و مستعد خطا — راحت می‌شه یه متد رو فراموش کرد یا پارامتر اشتباه دادش. خلاصه، خیلی چیزها می‌تونه اشتباه پیش بره.

### الگوی Facade به کمک میاد

توسعه‌دهنده‌ها یه facade پیاده می‌کنن که جلوی متدهای خاص می‌ایسته و یه کارکردِ متمرکز و مشخص رو در معرض دید می‌ذاره. توی مثالمون، facade یه متده به اسم `TransferMoney` که سه آرگومان می‌گیره: حساب برداشت، حساب واریز و مبلغ:

```csharp
public void TransferMoney(string fromAccount, string toAccount, decimal amount)
{
    ValidateAccountsExist(fromAccount, toAccount);
    ValidateSufficientFunds(fromAccount, amount);
    Withdraw(fromAccount, amount);
    Deposit(toAccount, amount);
    LogTransfer(fromAccount, toAccount, amount);
}
```

پشتِ‌صحنه، این متد از همون پنج متدی که ذکر شد استفاده می‌کنه — و هیچ کد اختصاصیِ جدیدی برای خودش نمی‌نویسه. به عبارت دیگه، facade کارکرد جدیدی اختراع نمی‌کنه؛ فقط یه کارکردِ موجود رو توی یه متدِ راحت‌برای‌استفاده بسته‌بندی می‌کنه.

### جمع‌بندی

استفاده از الگوی Facade کدت رو خیلی خواناتر و راحت‌تر برای استفاده می‌کنه و به‌شدت توصیه می‌شه.
