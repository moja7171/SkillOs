## دسکتاپ

اپلیکیشن‌های دسکتاپ، بچه‌های فقیر دنیای اپلیکیشن‌ان. توی دنیایی که وب API و کلاود همه‌جا حرفشونه، تقریباً کسی درباره‌ی اپ‌های دسکتاپ حرف نمی‌زنه — و دلیل خوبی هم داره.

اپلیکیشن‌های دسکتاپ، اپلیکیشن‌هایی هستن که عمدتاً روی PC اجرا می‌شن. مهمه که این‌ها رو از rich client apps‌ای که به وب API دسترسی دارن و فقط یه لایه‌ی بصریِ نازک روی داده‌ان، تفکیک کنیم. اینجا داریم درباره‌ی اپلیکیشنی حرف می‌زنیم که تمام منابعش — از جمله منطق و داده — روی خود PC هستن. این اپلیکیشن ممکنه برای کارهای خاصی مثل اعتبارسنجی لایسنس یا ارسال لاگ فعالیت از اینترنت استفاده کنه، ولی همچنان به‌صورت آفلاین هم کاملاً کاربردیه.

جنبه‌ی دیگه‌ی اپلیکیشن دسکتاپ، رابط کاربریشه. این اپلیکیشن‌ها برای کاربر نهایی طراحی می‌شن و معمولاً یه رابط کاربری عالی دارن. یه نمونه‌ی خوبش Microsoft Word‌ـه، که هم با اتصال اینترنت فعال کار می‌کنه، هم بدونش. البته آفلاین یه سری قابلیت رو از دست می‌دی — مثل اتصال به کلاود — ولی همچنان کاملاً کاربردی می‌مونه.

به خاطر استفاده‌ی گسترده از رایانش ابری و در دسترس‌بودن همه‌جانبه‌ی اینترنت، محبوبیت اپلیکیشن‌های دسکتاپ داره کاهش پیدا می‌کنه.

### کِی از اپلیکیشن دسکتاپ استفاده کنیم؟

عمدتاً برای اکشن‌های کاربرمحور مثل پردازش متن یا محاسبات و بازی‌های سنگین. ولی، باز هم، می‌شه یه عمر کامل به‌عنوان معمار کار کرد بدون اینکه حتی یه بار یه اپ دسکتاپ طراحی کنی.
