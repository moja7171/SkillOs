## دانلود و نصب

برو [python.org](https://python.org)، از قسمت Downloads آخرین نسخه رو بگیر، نصب‌کننده رو باز کن.

> اگه ویندوزی هستی، یه چک‌باکس می‌بینی به اسم «Add Python to PATH» — حتماً تیکش بزن! بدون این، بعداً نمی‌تونی پایتون رو از خط فرمان اجرا کنی و کلی سردرگم می‌شی.

## حالا مطمئن شو درست نصب شده

**ویندوز**: توی نوار جست‌وجو `cmd` بزن تا Command Prompt باز بشه، بعد بنویس:

```
python
```

**مک/لینوکس**: ترمینال رو باز کن (روی مک: Command+Space و بنویس Terminal) و بنویس:

```
python3
```

> نکته‌ی مهم: روی مک و لینوکس، `python` (بدون عدد) معمولاً یعنی پایتون ۲ قدیمی. همیشه `python3` بزن.

اگه یه پیام شبیه `Python 3.x.x` دیدی، عالیه، نصب شده. برای خروج: ویندوز `Ctrl+Z` بعد Enter، مک/لینوکس `Ctrl+D`.
