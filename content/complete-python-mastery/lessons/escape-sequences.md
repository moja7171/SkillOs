## یه مشکل کوچولو

فرض کن می‌خوای یه کوتیشن دوتایی وسط یه رشته‌ی خودش با کوتیشن دوتایی بذاری:

```python
course = "Python "programming""   # error!
```

پایتون همین که به دومین `"` می‌رسه، فکر می‌کنه رشته تموم شده — بقیه‌ش براش بی‌معنیه.

دو راه‌حل داری: یکی اینکه از کوتیشن تکی برای کل رشته استفاده کنی و کوتیشن دوتایی رو وسطش بذاری. راه دوم — اگه می‌خوای همچنان از کوتیشن دوتایی استفاده کنی — اینه که قبل از کوتیشن داخلی یه بک‌اسلش بذاری:

```python
course = "Python \"programming\""
```

این بک‌اسلش یه اسم خاص داره: **کاراکتر escape**. بهش می‌گیم داره کاراکتر بعد از خودشو «escape» می‌کنه، یعنی به پایتون می‌گه «این کوتیشن رو جدی نگیر، پایان رشته نیست».

## بقیه‌ی escape sequenceها

```python
print("Python \"programming\"")   # Python "programming"
print('Let\'s go')                 # Let's go
print("C:\\Users\\mosh")           # C:\Users\mosh
print("Python\nprogramming")       # prints on two lines
```

خط سوم رو دقت کن: بک‌اسلش دوتایی یعنی یه بک‌اسلش واقعی. `\n` هم یعنی خط جدید (newline) — یکی از پرکاربردترین escape sequenceهاست.

> راستی، `#` هم یه علامت خاصه ولی ربطی به escape نداره — باهاش کامنت می‌نویسی، یعنی یادداشتی که پایتون اصلاً اجراش نمی‌کنه:
> ```python
> # this is a comment, it doesn't run
> ```
