## اولین که اومد، اولین کسیه که می‌ره

**صف** (queue) برعکس پشته عمل می‌کنه: اولین چیزی که اضافه شده، اولین چیزیه که برداشته می‌شه. به این رفتار می‌گیم **FIFO** (مخفف first in, first out). دقیقاً مثل صف رستوران — اولین نفری که توی صف وایساده، اولین نفریه که می‌ره تو.

## چرا لیست برای صف مناسب نیست

از نظر فنی می‌شه لیست رو هم به‌عنوان صف استفاده کرد — عضو اول رو با `pop(0)` برمی‌داری. ولی یه مشکل داره: وقتی یه عضو رو از **ابتدای** یه لیست بزرگ حذف کنی، پایتون باید همه‌ی اعضای بعدی رو یکی یکی به چپ بشمره — اگه لیستت هزار عضو داشته باشه، حذف عضو اول یعنی جابه‌جایی ۹۹۹ تا عضو توی حافظه. برای صف‌های بزرگ، این کند می‌شه.

## راه‌حل: `deque`

برای همچین کاری، ماژول `collections` یه ساختار داده‌ی بهینه‌تر داره به اسم `deque` (مخفف double-ended queue):

```python
from collections import deque

queue = deque()

queue.append(1)
queue.append(2)
queue.append(3)

print(queue)
# deque([1, 2, 3])
```

## حذف از ابتدای صف

`deque` یه متد مخصوص برای حذف از **ابتدا** داره — بدون نیاز به جابه‌جایی بقیه‌ی اعضا:

```python
first = queue.popleft()
print(first)
# 1

print(queue)
# deque([2, 3])
```

`popleft()` دقیقاً همون کاریه که `pop(0)` روی لیست می‌کنه، ولی به‌شکل بهینه — بدون توجه به اندازه‌ی صف، همیشه سریعه.

## چک‌کردن خالی‌بودن

دقیقاً مثل لیست، `deque` هم falsy می‌شه وقتی خالیه:

```python
if not queue:
    print("empty")
```

## جمع‌بندی

| | پشته (Stack) | صف (Queue) |
|---|---|---|
| رفتار | LIFO | FIFO |
| اضافه‌کردن | `append()` | `append()` |
| برداشتن | `pop()` (از انتها) | `popleft()` (از ابتدا، فقط روی deque) |
