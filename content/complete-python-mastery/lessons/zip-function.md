## ترکیب دو تا لیست جدا

فرض کن دو تا لیست جدا داری و می‌خوای اعضای هم‌ردیفشون رو با هم جفت کنی:

```python
list1 = [1, 2, 3]
list2 = [10, 20, 30]
```

می‌خوایم به این برسیم: `[(1, 10), (2, 20), (3, 30)]` — یعنی عضو اول هر لیست با هم، عضو دوم هر لیست با هم، و همین‌طور.

`map` و `filter` و list comprehension همه فقط روی **یه** پیمایش‌پذیر کار می‌کنن. برای ترکیب **چند تا** پیمایش‌پذیر با هم، از تابع `zip` استفاده می‌کنیم.

## استفاده از `zip`

```python
list1 = [1, 2, 3]
list2 = [10, 20, 30]

combined = list(zip(list1, list2))
print(combined)
# [(1, 10), (2, 20), (3, 30)]
```

`zip` یه شیء پیمایش‌پذیر برمی‌گردونه (مثل `map` و `filter`)، پس برای گرفتن یه لیست واقعی، دورش `list()` می‌ذاریم.

## هر پیمایش‌پذیری، نه فقط لیست

`zip` هر تعداد پیمایش‌پذیر می‌تونه بگیره — نه فقط لیست:

```python
combined = list(zip([1, 2, 3], "abc"))
print(combined)
# [(1, 'a'), (2, 'b'), (3, 'c')]
```

اینجا یه لیست عددی رو با یه رشته ترکیب کردیم — چون رشته هم پیمایش‌پذیره، هر کاراکترش یکی‌یکی جفت شد با اعضای لیست.

## جمع‌بندی

اگه بخوای بدونی برای کدوم کار کدوم ابزار مناسبه:

| هدف | ابزار |
|---|---|
| تبدیل شکل هر عضو یه پیمایش‌پذیر | `map` یا list comprehension |
| فیلترکردن بعضی اعضا | `filter` یا list comprehension با `if` |
| ترکیب چند پیمایش‌پذیر با هم | `zip` |
