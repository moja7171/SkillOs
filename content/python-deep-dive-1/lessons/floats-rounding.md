> این درس دو ویدیو دارد: بخش نظری و بخش کدنویسی.

## round(x, n): گرد کردن به نزدیک‌ترین مضرب 10⁻ⁿ

`round` built-in است (import نمی‌خواهد). `n` پیش‌فرض ۰ است و می‌تواند **منفی** باشد — پس «تعداد رقم اعشار» توصیف کاملی نیست؛ `round` به **نزدیک‌ترین مضرب `10⁻ⁿ`** گرد می‌کند:

| n | مضرب | مثال |
|---|---|---|
| 0 | 1 (اعداد صحیح) | `round(1.23)` → `1` |
| 1 | 0.1 | `round(1.23, 1)` → `1.2` |
| 3 | 0.001 | `round(1.8888, 3)` → `1.889` |
| −1 | 10 | `round(18.2, -1)` → `20` |
| −2 | 100 | `round(888.88, -2)` → `900` |
| −3 | 1000 | `round(888.88, -3)` → `1000` |
| −4 | 10000 | `round(888.88, -4)` → `0` (به صفر نزدیک‌تر است) |

نکته‌ی نوع: بدون `n`، خروجی **int** است؛ با `n` (حتی `n=0`)، خروجی **همان نوع ورودی** است:

```python
round(1.9)       # 2      ← int
round(1.9, 0)    # 2.0    ← float
```

## تساوی (tie): جایی که غافلگیر می‌شوی

`1.25` از `1.2` و `1.3` به یک فاصله است. در مدرسه یاد گرفتیم «به بالا گرد کن» — که اسم بهترش **دور شدن از صفر** است (برای `−1.25` می‌شود `−1.3`). ولی پایتون:

```python
round(1.25, 1)     # 1.2   ← not 1.3!
round(1.35, 1)     # 1.4
round(-1.25, 1)    # -1.2
round(-1.35, 1)    # -1.4
```

این **banker's rounding** است (استاندارد IEEE 754): به نزدیک‌ترین، و در تساوی، به گزینه‌ای که **رقم معنادار آخرش زوج** باشد. `1.25` بین `1.2` (۲ زوج) و `1.3` (۳ فرد) → `1.2`. `1.35` بین `1.3` و `1.4` (۴ زوج) → `1.4`.

با `n` منفی هم همین: `round(15, -1)` → `20` و `round(25, -1)` → `20` — هر دو به سمت ۲ که زوج است.

## چرا؟ چون سوگیری کمتری دارد

اگر همیشه از صفر دور شوی، در هر تساوی کمی «اضافه» می‌دهی و روی میلیاردها تراکنش این «غبار اعشاری» جمع می‌شود — همان چیزی که کلاه‌برداری‌های skimming بانکی از آن استفاده می‌کردند. مثال مدرس: میانگین `0.5, 1.5, 2.5` برابر `1.5` است. با گرد کردن معمولی (۱، ۲، ۳) میانگین می‌شود `2.0`؛ با banker's (۰، ۲، ۲) می‌شود `1.33` — نزدیک‌تر به واقعیت. سوگیری کامل از بین نمی‌رود، ولی کمتر می‌شود.

## اگر واقعاً «دور از صفر» می‌خواهی

پایتون این را برای float ندارد (برای `Decimal` دارد — درس‌های بعد). ترفند رایج اینترنتی `int(x + 0.5)` برای مثبت‌ها کار می‌کند ولی برای منفی‌ها غلط است: `int(-10.3 + 0.5)` → `-9`. باید علامت را در نظر بگیری:

```python
from math import copysign

def _round(x):
    """Round to nearest, ties away from zero. Integers only."""
    return int(x + copysign(0.5, x))

round(1.5), _round(1.5)      # 2, 2
round(2.5), _round(2.5)      # 2, 3   ← the difference is at the tie
round(-1.5), _round(-1.5)    # -2, -2
round(-2.5), _round(-2.5)    # -2, -3
```

`copysign(0.5, x)` مقدار `0.5` را با علامت `x` برمی‌گرداند (پایتون تابع `sign` ندارد). اسم `_round` با زیرخط، تا `round` built-in را پنهان نکند.
