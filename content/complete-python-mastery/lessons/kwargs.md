## نسخه‌ی کلیدی `*args`

درس قبل با `*` یاد گرفتیم چطور تعداد نامشخصی **آرگومان معمولی** بگیریم. حالا یه نسخه‌ی مشابه هست، با `**` (دو ستاره)، برای گرفتن تعداد نامشخصی **آرگومان کلیدی**:

```python
def save_user(**user):
    print(user)


save_user(id=1, name="John", age=22)
```

خروجی:
```
{'id': 1, 'name': 'John', 'age': 22}
```

## این چیه که چاپ شد؟

اون آکولادها (`{ }`) با جفت‌های کلید-مقدار (`key: value`)، یه **دیکشنری** (dictionary) هستن — یه نوع پیچیده‌ی دیگه‌ی پایتون که بعداً کامل می‌بینیش. وقتی یه پارامتر رو با `**` تعریف می‌کنی، پایتون هر آرگومان کلیدی‌ای که بهش بدی رو خودکار توی یه دیکشنری جمع می‌کنه — اسم آرگومان می‌شه کلید، مقدارش می‌شه مقدار همون کلید.

## دسترسی به مقادیر دیکشنری

با نماد کروشه، می‌تونی مقدار هر کلید رو بگیری:

```python
def save_user(**user):
    print(user["id"])
    print(user["name"])


save_user(id=1, name="John", age=22)
```

خروجی:
```
1
John
```

## جمع‌بندی `*args` و `**kwargs`

- `*args` (یا هر اسم دیگه‌ای با یه `*`): تعداد نامشخصی آرگومان معمولی → توی تابع، یه **تاپل**.
- `**kwargs` (یا هر اسم دیگه‌ای با دو `*`): تعداد نامشخصی آرگومان کلیدی → توی تابع، یه **دیکشنری**.

> نکته: `args` و `kwargs` فقط اسم‌های قراردادی و رایج‌ان؛ خود پایتون مجبورت نمی‌کنه دقیقاً همین‌ها رو بنویسی، فقط `*`/`**` هستن که معنا می‌دن. ولی چون خیلی رایجن، بهتره همین اسم‌ها رو نگه داری تا کدت برای بقیه هم آشنا بیاد.
