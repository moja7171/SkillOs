## تبدیل یه لیست به شکل دیگه

همون لیست سفارش‌ها رو در نظر بگیر:

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]
```

فرض کن فقط قیمت‌ها رو می‌خوای، یه لیست جدا از اعداد. راه پایه:

```python
prices = []
for item in items:
    prices.append(item[1])

print(prices)
# [10, 5, 15]
```

## راه کوتاه‌تر: تابع `map`

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]

x = map(lambda item: item[1], items)
print(x)
# <map object at ...>
```

`map(تابع, پیمایش‌پذیر)` همون تابع رو روی **تک‌تک اعضای** پیمایش‌پذیر اعمال می‌کنه. نتیجه یه شیء `map` ه — خودش پیمایش‌پذیره، ولی لیست نیست.

## گرفتن نتیجه به‌شکل لیست

```python
prices = list(map(lambda item: item[1], items))
print(prices)
# [10, 5, 15]
```

می‌تونی مستقیم روی شیء `map` هم پیمایش کنی (`for p in x`)، یا با `list()` بهش تبدیلش کنی — دقیقاً مثل هر پیمایش‌پذیر دیگه‌ای.

## جمع‌بندی

`map` جایگزین کوتاه‌تر همون حلقه‌ی بالاست: یه تابع (معمولاً لامبدا) رو می‌گیره، روی هر عضو یه پیمایش‌پذیر اعمالش می‌کنه، و یه پیمایش‌پذیر جدید (تبدیل‌شده) برمی‌گردونه.
