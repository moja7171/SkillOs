## یه ساختار سریع‌تر، فقط برای اعداد

لیست‌ها همه‌کاره‌ن، ولی اگه با یه دنباله‌ی **بزرگ از اعداد** سروکار داری (مثلاً ۱۰٬۰۰۰ تا یا بیشتر)، پایتون یه ساختار سریع‌تر و کم‌حجم‌تر هم داره: **آرایه** (array).

> نکته‌ی مهم: تفاوت کارایی آرایه و لیست فقط توی دنباله‌های خیلی بزرگ محسوسه. برای ۹۰٪ کارهای روزمره، همون لیست کاملاً کافیه. اگه مشکل کارایی نداری، دنبال بهینه‌سازی نباش — مشکلی که وجود نداره رو حل نکن.

## ساخت یه آرایه

```python
from array import array

numbers = array("i", [1, 2, 3])
print(numbers)
```

آرگومان اول (`"i"`) یه **type code**ه — یه حرف که نوع اعضای آرایه رو مشخص می‌کنه. `"i"` یعنی عدد صحیح با علامت (signed integer). لیست کامل type codeها توی مستندات رسمی پایتون هست.

## متدهای آشنا

آرایه هم متدهای مشابه لیست داره:

```python
numbers.append(4)
numbers.insert(0, 0)
numbers.pop()
numbers.remove(2)

print(numbers[0])
```

## فرق اصلی: همه‌ی اعضا باید یه نوع باشن

```python
numbers = array("i", [1, 2, 3])
numbers[0] = 1.5
# TypeError: integer argument expected, got float
```

برخلاف لیست (که می‌تونه هر ترکیبی از انواع رو داشته باشه)، آرایه فقط یه نوع مشخص رو قبول می‌کنه — همونی که موقع ساختش با type code تعیین کردی. برای همین جمع‌وجورتر و سریع‌تره: پایتون از قبل می‌دونه هر عضو دقیقاً چه شکلیه.

## جمع‌بندی

برای کارهای معمولی، از لیست یا تاپل استفاده کن. فقط وقتی با یه دنباله‌ی خیلی بزرگ از اعداد سروکار داری **و** واقعاً با مشکل کارایی مواجه شدی، سراغ آرایه برو.
