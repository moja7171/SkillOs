## ساخت اولین کلاس

بیا یه کلاس `Point` بسازیم:

```python
class Point:
    def draw(self):
        print("draw")
```

## قانون نام‌گذاری کلاس

برای اسم متغیر و تابع، از `snake_case` استفاده می‌کنیم (حروف کوچیک، کلمات جدا با `_`). برای اسم **کلاس**، قرارداد فرق داره — **Pascal case**: حرف اول هر کلمه بزرگ، بدون زیرخط. مثلاً `Point` یا `ShoppingCart`، نه `point` یا `shopping_cart`.

## پارامتر `self`

هر متدی که توی یه کلاس تعریف می‌کنی، باید حداقل یه پارامتر داشته باشه — طبق قرارداد، اسمش رو `self` می‌ذاریم. توی درس بعدی دقیق‌تر می‌بینیم `self` دقیقاً چیه؛ فعلاً همین‌قدر بدون که هر متد کلاس بهش نیاز داره.

## ساختن یه آبجکت

```python
point = Point()
point.draw()
# draw
```

برای ساختن یه آبجکت از یه کلاس، دقیقاً مثل صدازدن یه تابع، اسم کلاس رو با پرانتز می‌نویسیم. این عبارت یه آبجکت جدید از نوع `Point` برمی‌گردونه.

## چک‌کردن نوع یه آبجکت

```python
print(type(point))
# <class '__main__.Point'>
```

`__main__` اسم ماژولیه که این کد توشه — بیشتر درباره‌ی ماژول‌ها بعداً توی دوره می‌خونیم. برای چک‌کردن اینکه یه آبجکت از یه کلاس خاص ساخته شده یا نه، از `isinstance` استفاده کن:

```python
print(isinstance(point, Point))
# True

print(isinstance(point, int))
# False
```

## `Point` هنوز چیزی کم داره

الان `Point` هیچ مقدار اولیه‌ای (مثل مختصات x و y) نداره. برای دادن مقدار اولیه به یه آبجکت موقع ساختنش، به یه **سازنده** (constructor) نیاز داریم — موضوع درس بعدی.
