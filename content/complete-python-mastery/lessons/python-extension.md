## VS Code رو حرفه‌ای کن

با نصب افزونه‌ی رسمی **Python**، VS Code تبدیل می‌شه به یه IDE کامل. این افزونه چی بهت می‌ده؟

- **Linting**: قبل از اجرا، خطاهای احتمالی کدت رو نشون می‌ده.
- **Debugging**: گام‌به‌گام کدت رو اجرا می‌کنی تا خطاها رو پیدا و رفع کنی.
- **تکمیل خودکار (autocompletion)**: لازم نیست هر کاراکتر رو دستی تایپ کنی.
- **فرمت‌بندی خودکار**: کدت خودش مرتب و خوانا می‌شه.
- **تست خودکار (unit testing)**: می‌تونی برای کدت تست بنویسی و خودکار اجراش کنی.
- **قطعه‌کدهای آماده (snippets)**: بلوک‌های کد پرتکرار رو سریع تولید می‌کنی.

هیچ‌کدوم رو الان حفظ نکن — یکی‌یکی توی طول دوره باهاشون آشنا می‌شی.

## نصبش کن

از تب Extensions توی VS Code، دنبال «Python» بگرد و نصبش کن (بعدش یه Reload لازمه). بعد از نصب، پایین‌سمت‌چپ VS Code نسخه‌ی پایتونِ فعال رو نشون می‌ده — مطمئن شو پایتون ۳ انتخاب شده، نه ۲.

> نسخه‌ی امروزیِ افزونه بیشتر این امکانات رو (از جمله لینتر) خودش داخلی داره، بدون نیاز به نصب دستی ابزار جدا. ممکنه دقیقاً چیزی که توی ویدیو می‌بینی رو نبینی، ولی مفهوم و هدفش همونه.
