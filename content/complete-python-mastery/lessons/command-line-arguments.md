## چطور یه برنامه ورودی از خط فرمان می‌گیره

وقتی یه فایل پایتون رو اجرا می‌کنی، خودِ این دستور هم یه‌جور ارسال آرگومانه:

```bash
python3 app.py
```

پایتون این آرگومان‌ها رو توی یه لیست به اسم `sys.argv` در اختیارمون می‌ذاره:

```python
import sys

print(sys.argv)
```

## اولین عضو، همیشه اسم فایله

```bash
python3 app.py hello 1234
```

با اجرای دستور بالا، `sys.argv` این‌طوری می‌شه:

```python
['app.py', 'hello', '1234']
```

اولین عضو **همیشه** اسم فایل درحال‌اجراست — حتی اگه هیچ آرگومان اضافه‌ای ندی، `sys.argv` باز هم حداقل یه عضو داره. بقیه‌ی آرگومان‌ها به همون ترتیبی که توی خط فرمان نوشتی، به‌عنوان **رشته** (حتی اگه عدد به‌نظر برسن) توی لیست میان.

## کاربرد: چک‌کردن اینکه آرگومان داده شده یا نه

```python
import sys

if len(sys.argv) == 1:
    print("usage: python3 app.py <password>")
else:
    password = sys.argv[1]
    print(password)
```

چون اولین عضو همیشه اسم فایله، `len(sys.argv) == 1` یعنی «کاربر هیچ آرگومانی نداده». اگه آرگومانی داده باشه، `sys.argv[1]` اولین آرگومان واقعیه.

```bash
python3 app.py
# usage: python3 app.py <password>

python3 app.py 1234
# 1234
```

## جمع‌بندی

`sys.argv` یه لیسته که مقدار اولش همیشه اسم فایل درحال‌اجراست، و بقیه‌ی اعضاش آرگومان‌هایی هستن که موقع اجرا از خط فرمان دادی — همه به‌شکل رشته.
