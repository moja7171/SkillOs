## `*` در سمت چپ: «بقیه»

اولی را می‌خواهی و بقیه را یک‌جا:

```python
l = [1, 2, 3, 4, 5, 6]

a = l[0]; b = l[1:]          # with slicing
a, b = l[0], l[1:]           # same, one line
a, *b = l                    # a=1, b=[2, 3, 4, 5, 6]
```

دو مزیت نسبت به slicing: تمیزتر است، و **روی هر iterable** کار می‌کند — نه فقط sequenceهای ایندکس‌پذیر (set و dict slice نمی‌شوند).

```python
a, *b = (-10, 5, 2, 100)     # b = [5, 2, 100]   ← always a list, even from a tuple
a, *b = 'XYZ'                # b = ['Y', 'Z']
a, b, *c = 1, 2, 3, 4, 5     # c = [3, 4, 5]
a, b, *c, d = 1, 2, 3, 4, 5  # c = [3, 4], d = 5
a, *b, c, d = 'python'       # b = ['y', 't', 'h'], c='o', d='n'
a, b, *c = ...               # only one * per level: a, *b, *c is an error
```

سمت چپ می‌تواند list هم باشد (`[a, b, c] = 'XYZ'`)، فرقی نمی‌کند.

## `*` در سمت راست: پهن کردن

```python
l1 = [1, 2, 3]; l2 = [4, 5, 6]
[*l1, *l2]                   # [1, 2, 3, 4, 5, 6]
[*l1, *'XYZ']                # [1, 2, 3, 'X', 'Y', 'Z']
{*l1, *{3, 4, 5}}            # set: merge without duplicates
{*s1, *s2, *s3, *s4}         # instead of s1.union(s2, s3, s4)
*c, = 'python'               # a trick: string → list of characters (or list('python'))
```

## set و dict: مجاز، ولی بی‌ترتیب

```python
s = {10, -99, 3, 'd'}
a, *b, c = s                 # works; but "first" and "last" are meaningless
```

سمت راست مفیدتر است: `[*d1, *d2, *d3]` **کلیدها** را (با تکرار) در یک لیست می‌ریزد؛ `{*d1, *d2, *d3}` بدون تکرار.

## `**` برای dict: کلید *و* مقدار

`*` روی dict فقط کلیدها را می‌دهد. برای جفت‌ها، `**` — که **فقط در سمت راست** و فقط برای dict مجاز است:

```python
d1 = {'p': 1, 'y': 2}
d2 = {'t': 3, 'h': 4}
d3 = {'h': 5, 'o': 6, 'n': 7}
{**d1, **d2, **d3}           # {'p': 1, 'y': 2, 't': 3, 'h': 5, 'o': 6, 'n': 7}
```

`'h'` در d2 و d3 هست؛ **آخری برنده است** (۵). کاربرد کلاسیک: `{**defaults, **user_settings}` — تنظیمات کاربر روی پیش‌فرض‌ها را بازنویسی می‌کند و جاهای خالی پر می‌مانند. با literal هم ترکیب می‌شود: `{'a': 10, **d1}` (a=1 — d1 آخر آمده) در برابر `{**d1, 'a': 10}` (a=10).

## تودرتو

```python
a, b, (c, d) = [1, 2, ['X', 'Y']]           # c='X', d='Y'
a, *b, (c, d, e) = [1, 2, 3, 'XYZ']         # b=[2, 3], c='X', d='Y', e='Z'
a, *b, (c, *d) = [1, 2, 3, 'python']        # b=[2, 3], c='p', d=['y','t','h','o','n']
```

مورد آخر دو `*` دارد ولی در **دو سطح** مختلف — مجاز است. با slicing همین کار می‌شود ولی دست‌وپاگیرتر (`l[0], l[1:-1], l[-1][0], list(l[-1][1:])`) و فقط برای انواع ایندکس‌پذیر.
