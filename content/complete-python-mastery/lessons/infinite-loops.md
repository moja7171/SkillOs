## یه حلقه که هیچ‌وقت تموم نمی‌شه

اگه شرط `while` همیشه `True` باشه، حلقه تا ابد ادامه پیدا می‌کنه. به این می‌گیم **حلقه‌ی بی‌نهایت** (infinite loop):

```python
while True:
    print("hi")
```

این کد هیچ‌وقت خودش متوقف نمی‌شه — باید یه جایی با `break` ازش بزنی بیرون.

## چرا اصلاً از این استفاده کنیم؟

بریم سراغ همون مثال «تا وقتی quit تایپ نشه ادامه بده»، این‌بار با یه حلقه‌ی بی‌نهایت:

```python
while True:
    command = input("> ")
    if command.lower() == "quit":
        break
    print("echo:", command)
```

با این روش، دیگه نیازی نیست از اول `command` رو با یه مقدار خالی مقداردهی کنی — چون شرط حلقه از اول `True`ه و به هیچ متغیری وابسته نیست. از نظر رفتار، این کد دقیقاً همون کاری رو می‌کنه که نسخه‌ی قبلی (با `while command.lower() != "quit":`) می‌کرد، فقط یه خط کوتاه‌تره.

## مراقب باش

یادت باشه هر حلقه‌ی بی‌نهایتی که می‌نویسی، حتماً یه راه خروج (معمولاً یه `break` پشت یه شرط) داشته باشه. اگه یادت بره، برنامه‌ت تا ابد اجرا می‌مونه — و اگه توی اون حلقه داری حافظه مصرف می‌کنی (مثلاً چیزی رو به یه لیست اضافه می‌کنی)، ممکنه برنامه‌ت بالاخره حافظه‌ی سیستم رو پر کنه و کرش کنه.
