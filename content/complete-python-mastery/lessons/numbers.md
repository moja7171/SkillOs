## سه نوع عدد

توی پایتون سه جور عدد داریم. دوتاشو قبلاً دیدی:

```python
x = 3          # int
y = 3.14       # float
z = 1 + 2j     # complex
```

`int` عدد صحیحه، `float` عدد اعشاری، و `complex` عدد مختلط. عدد مختلط (complex) همون چیزیه که توی ریاضی و مهندسی برق باهاش سروکار داری (`a + bi`، فقط توی پایتون به‌جای `i` می‌نویسیم `j`). اگه داری اپلیکیشن وب می‌سازی، احتمالاً هیچ‌وقت بهش نیاز نداری — فقط بدون که هست.

## عملیات ریاضی معمولی

```python
print(10 + 3)    # 13
print(10 - 3)    # 7
print(10 * 3)    # 30
print(10 / 3)    # 3.3333333333333335
print(10 // 3)   # 3
print(10 % 3)    # 1
print(10 ** 3)   # 1000
```

نکته‌ی مهم: پایتون دو نوع تقسیم داره. `/` همیشه یه عدد اعشاری بهت می‌ده، ولی `//` فقط قسمت صحیحش رو نگه می‌داره و اعشار رو دور می‌ندازه. `%` باقی‌مونده‌ی تقسیمه، و `**` یعنی توان (اینجا ۱۰ به توان ۳).

## یه میان‌بر باحال

فرض کن می‌خوای یه متغیر رو با یه عدد جمع کنی و همون‌جا ذخیره کنی:

```python
x = 10
x = x + 3   # x is now 13
```

می‌تونی کوتاه‌ترش کنی:

```python
x += 3   # does exactly the same thing
```

این رو **عملگر انتساب ترکیبی (augmented assignment)** می‌گیم و برای همه‌ی عملگرهای بالا کار می‌کنه: `-=`، `*=`، `/=` و بقیه.
