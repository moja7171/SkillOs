## چهارتا قانون طلایی

**۱. اسم بذار که معنی بده.** `students_count` یعنی تعداد دانشجو، `course_name` یعنی اسم دوره — واضحه چی هستن. اسم‌های مبهم مثل `cn` یا `c1` رو کنار بذار؛ وقتی یه ماه بعد خودت هم کدتو باز کنی، هیچی یادت نمیاد که `c1` چی بود! (استثنا: برای چیزایی مثل مختصات، `x` و `y` و `z` کاملاً قابل قبوله.)

**۲. همه‌چی حروف کوچیک.** نه بزرگ، نه Title Case.

**۳. زیرخط جای فاصله.** پایتون توی اسم متغیر فاصله قبول نمی‌کنه (`course name` نامعتبره)، پس می‌نویسیم `course_name`.

**۴. دور علامت مساوی فاصله بذار.**

```python
course_name = "Python programming"    # good
course_name="Python programming"      # bad
```

## کد تمیز بنویس، نه فقط چون ابزار می‌گه

اگه یادت بره این قوانین رو رعایت کنی، اشکالی نداره — ابزار فرمت‌بندی (همون autopep8 از قبل) خودش موقع ذخیره درستش می‌کنه. ولی هدف اینه که خودت عادت کنی کد تمیز بنویسی، نه اینکه همیشه منتظر ابزار بمونی. کد خوب باید مثل یه داستان روان خونده بشه، نه یه معما.
