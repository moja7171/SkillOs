## کوتیشن تکی یا دوتایی؟

هر دو کار می‌کنن، فرقی نداره — فقط سعی کن توی کل کدت یه‌دست باشی:

```python
course = "Python programming"
```

اگه متنت چندخطیه، از سه‌تا کوتیشن استفاده کن:

```python
message = """
Hi John,
this is Mosh from codewithmosh.com,
blah blah blah.
"""
```

## طول یه رشته رو بگیر

`len` یه تابع درونیه که طول (تعداد کاراکترهای) یه رشته رو بهت می‌ده:

```python
course = "Python programming"
print(len(course))   # 18
```

یادته گفتیم برای صدا زدن تابع باید پرانتز بذاری؟ اینجا هم داخل پرانتز، رشته‌مون رو به‌عنوان **آرگومان (argument)** — یعنی ورودی تابع — می‌فرستیم.

## دسترسی به یه کاراکتر خاص

با براکت مربعی می‌تونی بری سراغ یه کاراکتر خاص:

```python
print(course[0])    # P
```

توی پایتون (مثل خیلی زبون‌های دیگه)، شمارش از صفر شروع می‌شه — پس اولین کاراکتر ایندکس ۰ داره، نه ۱.

می‌تونی از آخر هم بشماری، با ایندکس منفی:

```python
print(course[-1])   # g
```

این آخرین کاراکتر رشته‌ست.

## برش زدن (Slicing) یه رشته

می‌خوای فقط یه تیکه از رشته رو برداری؟

```python
print(course[0:3])   # Pyt
print(course[:3])    # Pyt
print(course[0:])    # Python programming
print(course[:])     # Python programming
```

خط اول از ایندکس ۰ تا ۲ می‌ره (ایندکس ۳ جزوش نیست!). خط دوم دقیقاً همون نتیجه رو می‌ده چون وقتی `start` رو ننویسی، پیش‌فرضش صفره. خط سوم از ایندکس ۰ تا آخر رشته می‌ره. خط چهارم هم یه کپی کامل از کل رشته‌ست.

قانونش ساده‌ست: `course[start:end]` یعنی از `start` شروع کن، تا قبل از `end` برو (خود `end` جزوش نیست).
