## `range` واقعاً چیه؟

تا الان با `type` آشنا شدی — می‌تونی نوع هر مقداری رو باهاش ببینی:

```python
print(type(5))
# <class 'int'>
```

حالا بیا ببینیم `range(5)` چه نوعیه:

```python
print(type(range(5)))
# <class 'range'>
```

جالبه! `range` خودش یه نوع جداگانه‌ست، نه عدد و نه رشته. توی پایتون علاوه بر نوع‌های اولیه (عدد، رشته، بولی) یه سری نوع پیچیده‌تر هم داریم — `range` یکی از اوناست، و بعداً توی دوره با خیلی‌های دیگه‌شون هم آشنا می‌شی.

## چرا می‌تونیم توی `for` ازش استفاده کنیم؟

چیزی که `range` رو مخصوص می‌کنه اینه که **پیمایش‌پذیره** (iterable) — یعنی می‌شه روش پیمایش کرد، همون کاری که توی حلقه‌ی `for` می‌کنیم. برای همینه که این کد کار می‌کنه:

```python
for x in range(3):
    print(x)
```

## `range` تنها پیمایش‌پذیر نیست

رشته‌ها هم پیمایش‌پذیرن:

```python
for letter in "Python":
    print(letter)
```

خروجی:
```
P
y
t
h
o
n
```

هر تکرار، `letter` یه کاراکتر از رشته رو می‌گیره. **لیست‌ها** (list) هم پیمایش‌پذیرن — یه نوع دیگه که بعداً کامل می‌بینیشون، برای نگه‌داشتن یه مجموعه از مقادیر:

```python
for name in ["Ali", "Sara", "Reza"]:
    print(name)
```

## یه نگاه به جلو

بعداً توی دوره یاد می‌گیری چطور خودت یه **نوع سفارشی پیمایش‌پذیر** بسازی. مثلاً فرض کن یه «سبد خرید» (shopping cart) ساختی؛ می‌تونی طوری طراحیش کنی که این کد روش کار کنه:

```python
for item in shopping_cart:
    print(item)
```

`shopping_cart` نه عدده نه رشته نه لیست — یه ساختار کاملاً سفارشیه که خودت طراحیش کردی، ولی چون پیمایش‌پذیرش کردی، توی `for` هم مثل بقیه کار می‌کنه. فعلاً همین‌قدر بدون که **پیمایش‌پذیر بودن** یعنی «می‌شه توی `for` ازش استفاده کرد» — جزئیات چطوریش رو بعداً می‌بینی.
