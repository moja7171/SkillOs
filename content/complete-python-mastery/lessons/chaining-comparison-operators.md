## یه قانون: سن باید بین ۱۸ تا ۶۵ باشه

فرض کن می‌خوای بررسی کنی سن بین ۱۸ و ۶۵ (شامل ۱۸، بدون ۶۵) هست یا نه. با چیزی که تا الان بلدی، این‌طوری می‌نویسیش:

```python
age = 22

if age >= 18 and age < 65:
    print("Eligible")
```

کار می‌کنه، ولی پایتون یه راه تمیزتر هم داره. همین قانون رو می‌تونی این‌طوری هم بنویسی:

```python
age = 22

if 18 <= age < 65:
    print("Eligible")
```

## چرا این کار می‌کنه

این دقیقاً همون چیزیه که توی ریاضی هم می‌نویسی — «۱۸ ≤ سن < ۶۵». پایتون اجازه می‌ده مقایسه‌ها رو زنجیره کنی، و نتیجه‌ش دقیقاً معادل نوشتن با `and`ه:

```python
18 <= age < 65
# exactly the same as:
18 <= age and age < 65
```

خط دوم (زنجیره‌ای) هم کوتاه‌تره هم خواناتر — به همین می‌گیم **زنجیره‌کردن عملگرهای مقایسه‌ای** (chaining comparison operators).

می‌تونی هر تعداد مقایسه‌ای که بخوای زنجیره کنی، نه فقط دوتا:

```python
print(1 < 2 < 3 < 4)  # True
```
