## عبارت `if`

توی تقریباً هر برنامه‌ای، یه جایی باید تصمیم بگیری. اونجاست که از `if` استفاده می‌کنی:

```python
temperature = 35

if temperature > 30:
    print("It's warm")
    print("Drink water")

print("Done")
```

بعد از `if` یه **شرط** میاد — یه عبارت بولی که یا `True`ه یا `False`. اگه `True` باشه، بلوکی که زیرش با تورفتگی (indentation) نوشته شده اجرا می‌شه.

> نکته: حتماً بعد از شرط، یه `:` (دونقطه) بذار — از اشتباه‌های رایج مبتدیاست که فراموشش می‌کنن.

## تورفتگی مهمه!

هر خطی که زیر `if` با فاصله شروع بشه، عضو همون بلوکه. هر چقدر خط بخوای می‌تونی همونجا بنویسی، فقط باید هم‌تراز باشن:

```python
if temperature > 30:
    print("It's warm")    # part of the if block
    print("Drink water")  # part of the if block

print("Done")  # no indentation -> always runs, condition true or not
```

اینجا `"Done"` بیرون بلوک `if`ه (تورفتگی نداره)، پس هر بار اجرا می‌شه — چه دما بالای ۳۰ باشه چه نباشه.

**یه اشتباه خیلی رایج:** بذار یه سناریو بگم. یکی از دوستات داره کد می‌زنه، می‌خواد وقتی دما بالای ۳۰ه هم `"It's warm"` چاپ بشه هم `"Drink water"`، ولی سهواً تورفتگی خط دوم رو حذف می‌کنه:

```python
if temperature > 30:
    print("It's warm")
print("Drink water")   # oops! no longer part of the if
```

حالا `"Drink water"` همیشه چاپ می‌شه، حتی وقتی دما سرده! نتیجه‌ای که دوستت می‌گیره با انتظارش فرق داره، و علتش رو نمی‌فهمه چون کد "اشتباه" به‌نظر نمی‌رسه — فقط یه فاصله جا افتاده.

## چند شرط با `elif`

وقتی بیشتر از یه حالت داری، از `elif` (مخفف else if) استفاده کن:

```python
temperature = 15

if temperature > 30:
    print("It's warm")
elif temperature > 20:
    print("It's nice")
else:
    print("It's cold")
```

هر چقدر بخوای می‌تونی `elif` داشته باشی، و در آخر می‌تونی یه `else` هم اضافه کنی — اگه هیچ‌کدوم از شرط‌های قبلی `True` نبود، بلوک `else` اجرا می‌شه. پایتون شرط‌ها رو به ترتیب از بالا چک می‌کنه؛ همین که یکی `True` شد، همون بلوک اجرا می‌شه و بقیه رو نادیده می‌گیره.
