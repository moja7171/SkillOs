## کدی که فقط یه بار اجرا می‌شه

توی یه ماژول، فقط تابع و کلاس تعریف نمی‌کنیم — هر دستور سطح‌بالای دیگه‌ای هم می‌تونیم بنویسیم. اون دستورها **اولین باری که ماژول لود می‌شه**، اجرا می‌شن — حتی اگه ماژول از چند جای مختلف برنامه import بشه، پایتون فقط یه بار لودش می‌کنه و کشش می‌کنه.

```python
# sales.py
print("sales initialized")


def calculate_tax():
    pass
```

```python
# app.py
import sales
```

با اجرای `app.py`، پیام `sales initialized` چاپ می‌شه — چون این خط توی سطح بالای ماژول نوشته شده، نه داخل یه تابع.

همین ایده رو می‌شه توی `__init__.py` یه پکیج هم استفاده کرد؛ کد داخل `__init__.py` یه پکیج، اولین باری که اون پکیج import بشه اجرا می‌شه.

## `__name__`: کی این ماژول رو صدا زده؟

هر ماژول یه ویژگی خودکار به اسم `__name__` داره. مقدارش بسته به این فرق می‌کنه که ماژول چطور اجرا شده:

- اگه ماژول **مستقیم** از خط فرمان اجرا بشه (`python sales.py`)، مقدار `__name__` می‌شه `"__main__"`.
- اگه ماژول **import** بشه (نه مستقیم اجرا)، مقدار `__name__` اسم کامل و فول‌کوالیفای‌شده‌ی خودشه (مثلاً `ecommerce.shopping.sales`).

## یه ماژول، دو کاربرد: هم اسکریپت، هم کتابخانه

با چک‌کردن `__name__`، می‌شه یه ماژول ساخت که هم به‌عنوان اسکریپت مستقل قابل‌اجراست، هم به‌عنوان یه ماژول قابل‌import توی برنامه‌های دیگه:

```python
# sales.py
def calculate_tax():
    pass


if __name__ == "__main__":
    print("sales started")
    calculate_tax()
```

- اگه `python sales.py` رو مستقیم اجرا کنی، `__name__` می‌شه `"__main__"`، پس شرط `True` می‌شه و `calculate_tax()` صدا زده می‌شه.
- اگه یه ماژول دیگه `sales` رو import کنه، `__name__` دیگه `"__main__"` نیست، پس این بلوک اصلاً اجرا نمی‌شه — فقط تابع `calculate_tax` در دسترس می‌مونه، بدون هیچ اثر جانبی اضافه.

## جمع‌بندی

این الگو (`if __name__ == "__main__":`) خیلی رایجه: بهت اجازه می‌ده یه فایل رو هم مستقیم تست/اجرا کنی، هم به‌عنوان یه کتابخانه‌ی تمیز توی بقیه‌ی برنامه استفاده کنی — بدون اینکه کد تستی یا نمایشی توی بقیه‌ی جاها هم اجرا بشه.
