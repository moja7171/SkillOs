## زیرخط برای خوانایی

```python
10_000_000          # 10000000   — vs 10000000: which is easier to count?
30_000.05           # floats too
0x_FF_FFFF          # 16777215
0x_F_F_F_F_F_F      # 16777215   — grouping is up to you
```

قواعد: زیرخط فقط **بین** ارقام (نه در ابتدا/انتها، نه دو تا پشت هم)؛ در هر پایه‌ای (`0b`, `0o`, `0x`) و در اعشار و توان هم مجاز.

## در قالب‌بندی رشته

`_` به‌عنوان جداکننده‌ی هزارگان (و هر ۴ رقم برای `b`, `o`, `x`, `X`):

```python
'{:_}'.format(10000)            # '10_000'
'{:_X}'.format(16777215)        # 'FF_FFFF'
f'{1234567.891:_.2f}'           # '1_234_567.89'
f'{1234567:,}'                  # '1,234,567'  — comma separator existed before
```

## در تبدیل رشته به عدد

```python
int('FF_FF', 16)                # 65535
int('0b_1_0000_0000', 2)        # 256
int('1_000')                    # 1000
float('1_000.5')                # 1000.5
```

نکته: اینها برای literal و تبدیل هستند؛ در نمایش پیش‌فرض (`str(10_000)`) زیرخطی نیست — `'10000'`.
