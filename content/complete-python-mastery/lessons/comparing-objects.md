## چرا `==` بین دو تا آبجکت `False` می‌ده؟

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y


p1 = Point(1, 2)
p2 = Point(1, 2)

print(p1 == p2)
# False
```

با اینکه `p1` و `p2` مقادیر یکسان دارن، `==` می‌گه `False`! چرا؟ چون به‌طور پیش‌فرض، `==` **آدرس حافظه**ی دو آبجکت رو مقایسه می‌کنه، نه محتواشون. `p1` و `p2` دو تا آبجکت جدا توی حافظه‌ان، پس نابرابرن — حتی اگه ویژگی‌هاشون یکی باشه.

## متد جادویی `__eq__`

برای اینکه `==` بر اساس **محتوا** مقایسه کنه، باید متد جادویی `__eq__` رو خودمون تعریف کنیم:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y


p1 = Point(1, 2)
p2 = Point(1, 2)

print(p1 == p2)
# True
```

`__eq__` دو تا پارامتر می‌گیره: `self` (آبجکت سمت چپ `==`) و `other` (آبجکت سمت راست). باید یه مقدار بولی برگردونه — `True` اگه دو آبجکت «برابر» حساب بشن.

## مقایسه‌های دیگه: `__gt__`، `__lt__`

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __gt__(self, other):
        return self.x > other.x and self.y > other.y


p1 = Point(10, 20)
p2 = Point(1, 2)

print(p1 > p2)
# True

print(p1 < p2)
# False
```

نکته‌ی جالب: فقط `__gt__` (بزرگ‌تر از) رو تعریف کردیم، ولی `<` هم بدون تعریف جدا درست کار می‌کنه — چون پایتون به‌طور خودکار `p1 < p2` رو معادل `p2 > p1` در نظر می‌گیره.

## جمع‌بندی

پایتون برای هر عملگر مقایسه (`==`، `!=`، `<`، `>`، `<=`، `>=`) یه متد جادویی متناظر داره (`__eq__`، `__ne__`، `__lt__`، `__gt__`، ...). با تعریف‌کردن این متدها، می‌تونی به پایتون بگی دو تا آبجکت از کلاس خودت چطور باید باهم مقایسه بشن.
