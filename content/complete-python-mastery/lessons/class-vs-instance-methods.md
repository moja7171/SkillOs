## متد نمونه در مقابل متد کلاس

همون فرقی که بین ویژگی نمونه و ویژگی کلاس دیدیم، بین **متدها** هم وجود داره. `draw` که قبلاً نوشتیم، یه **متد نمونه**ست — چون به یه آبجکت خاص نیاز داره تا کار کنه.

## کِی به متد کلاس نیاز داریم؟

گاهی یه متد به یه آبجکت خاص نیاز نداره. مثال: می‌خوایم یه راه سریع برای ساختن `Point` با مقدار اولیه‌ی `(0, 0)` داشته باشیم:

```python
zero_point = Point(0, 0)
```

این کار می‌کنه، ولی می‌شه بهتر هم نوشتش — با یه **متد کلاس** (class method) که یه `Point` آماده برمی‌گردونه. به این نوع متد می‌گیم **متد کارخانه‌ای** (factory method) — مثل یه کارخانه که آبجکت جدید تحویل می‌ده.

## تعریف متد کلاس

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    @classmethod
    def zero(cls):
        return cls(0, 0)
```

دو تا فرق کلیدی با متد نمونه:

1. به‌جای `self`، اولین پارامترش **`cls`** ه (مخفف class) — طبق قرارداد، نه اجبار نحوی.
2. یه **دکوراتور** (decorator) بالاش می‌ذاریم: `@classmethod`. دکوراتور یه‌جور «برچسب» ه که رفتار یه تابع/متد رو گسترش می‌ده — بعداً توی دوره عمیق‌تر می‌بینیمش.

## استفاده از متد کلاس

```python
point = Point.zero()
print(point.x, point.y)
# 0 0
```

داخل `zero`، پارامتر `cls` یه اشاره به **خود کلاس Point**ه — نه یه آبجکت خاص. با `cls(0, 0)`، دقیقاً همون کاری رو می‌کنیم که `Point(0, 0)` می‌کرد، فقط این‌بار پایتون خودش `cls` رو موقع صدازدن `Point.zero()` پاس می‌ده.

## چرا این روش بهتره؟

توی این مثال ساده، فرقش زیاد محسوس نیست. ولی وقتی ساختن یه آبجکت پیچیده‌تر بشه — چند تا مقدار خاص، چند خط منطق — متد کارخانه‌ای این پیچیدگی رو یه جا (داخل خود کلاس) جمع می‌کنه، به‌جای اینکه هر جای برنامه که یه `Point(0, 0)` لازم داری، همون مقادیر رو تکرار کنی.
