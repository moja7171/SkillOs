## دو معنی متفاوت از «برابر»

دو متغیر را می‌شود از دو زاویه‌ی کاملاً متفاوت مقایسه کرد:

1. **آیا به یک شیء اشاره می‌کنند؟** (مقایسه‌ی آدرس حافظه) → عملگر **identity**: `is`
2. **آیا state درونی‌شان یکی است؟** (مقایسه‌ی داده) → عملگر **equality**: `==`

| هدف | عملگر | نقیض |
|---|---|---|
| همان شیء؟ | `a is b` | `a is not b` |
| مقدار برابر؟ | `a == b` | `a != b` |

`is` همان کاری را می‌کند که قبلاً با `id(a) == id(b)` می‌کردیم. `==` یک مساوی است برای انتساب، دو مساوی برای مقایسه — قاطی‌شان نکن. `not a is b` هم کار می‌کند ولی `a is not b` خواناتر است.

## مثال‌ها

```python
a = 10
b = a
a is b     # True  (ارجاع مشترک)
a == b     # True

a = "hello"
b = "hello"
a is b     # True  — ولی روی این حساب نکن (interning)
a == b     # True

a = [1, 2, 3]
b = [1, 2, 3]
a is b     # False (دو شیء جدا)
a == b     # True  (محتوا یکی است؛ == درون لیست‌های تودرتو هم می‌رود)

a = 10
b = 10.0
a is b     # False (int و float نمی‌توانند یک شیء باشند)
a == b     # True  (به‌عنوان عدد برابرند)

a = 10 + 0j
b = 10.0
a == b     # True
```

قاعده‌ی عملی: برای مقایسه‌ی **مقدار** تقریباً همیشه `==` را می‌خواهی. `is` را وقتی به کار ببر که واقعاً می‌پرسی «همان شیء است؟» — و آن معمولاً فقط یک مورد است: `None`.

## `None` یک شیء واقعی است

`None` «هیچ‌چیز» نیست؛ یک شیء واقعی با آدرس و نوع (`NoneType`) است. تفاوتش این است که memory manager **همیشه** به همان یک شیء اشاره می‌دهد:

```python
a = None
b = None
c = None
a is b, a is c, a is None    # همه True

x = 10
x is None        # False
x is not None    # True
```

برای همین تست «آیا مقداری ندارد» را با `is None` می‌نویسند نه `== None`. کاربرد معمول: متغیری که هنوز مقدار ندارد (مثلاً محتوای فایلی که شاید وجود نداشته باشد) را به `None` می‌گذاری و بعداً با `if content is None:` تصمیم می‌گیری.
