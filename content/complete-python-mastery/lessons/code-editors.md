## ویرایشگر کد در برابر IDE

برای نوشتن کد پایتون دو گزینه داری:

- **ویرایشگر کد (code editor)**: مثل VS Code، Atom یا Sublime.
- **IDE** (مخفف Integrated Development Environment): ویرایشگر کدی با امکانات اضافه مثل تکمیل خودکار (autocompletion)، دیباگ و تست. معروف‌ترینش برای پایتون، PyCharm است.

تفاوت اصلی این است که IDE «باتری‌کامل» است — ابزارهای زیادی از قبل داخلش هست — در حالی‌که ویرایشگر کد سبک‌تر است و امکانات موردنیاز را با افزونه (extension) اضافه می‌کنی.

در این دوره از **VS Code** استفاده می‌شود؛ در درس بعدی با نصب یک افزونه، آن را به یک IDE کامل برای پایتون تبدیل می‌کنیم. از [code.visualstudio.com](https://code.visualstudio.com) آخرین نسخه‌ی VS Code را دانلود و نصب کن.
