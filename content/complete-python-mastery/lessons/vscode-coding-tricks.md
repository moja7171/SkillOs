> این درس دو ویدیو داره: میان‌برهای ویندوز، و میان‌برهای مک. هر کدوم مربوط به سیستم‌عامل خودته رو نگاه کن.

چندتا میان‌بر خیلی کاربردی برای سریع‌تر کدنویسی توی VS Code:

| کار | ویندوز/لینوکس | مک |
|---|---|---|
| رفتن به انتهای خط | `End` | `Fn + →` |
| رفتن به ابتدای خط | `Home` | `Fn + ←` |
| رفتن به ابتدای فایل | `Ctrl + Home` | `Fn + ↑` |
| رفتن به انتهای فایل | `Ctrl + End` | `Fn + ↓` |
| جابه‌جاکردن خط (یا خط‌های انتخاب‌شده) به بالا/پایین | `Alt + ↑/↓` | `Option + ↑/↓` |
| تکثیر خط (یا خط‌های انتخاب‌شده) | `Shift + Alt + ↓` | `Shift + Option + ↓` |
| کامنت‌کردن / برداشتن کامنت | `Ctrl + /` | `Cmd + /` |

## جابه‌جاکردن و تکثیر خط

به‌جای کات‌کردن یه خط و پیست‌کردنش یه جای دیگه، می‌تونی مستقیم با یه میان‌بر جابه‌جاش کنی. همین میان‌بر روی چند خط انتخاب‌شده هم کار می‌کنه. برای تکثیرکردن (duplicate) یه خط یا چند خط انتخاب‌شده هم یه میان‌بر مشابه هست — هرچقدر بخوای می‌تونی تکرارش کنی.

## کامنت‌کردن سریع

به‌جای اینکه دستی `#` اول خط بذاری، خط (یا خط‌های انتخاب‌شده) رو انتخاب کن و میان‌بر کامنت رو بزن — با همون میان‌بر می‌تونی کامنت رو هم برداری، یعنی toggle می‌شه.

## تایپ سریع‌تر با IntelliSense

لازم نیست اسم کامل یه متغیر یا تابع (مثل `multiply`) رو کامل تایپ کنی. چند تا راه داری:
- چند حرف اول رو بنویس (`mul`) و از لیست پیشنهادی IntelliSense، Enter بزن.
- یا حروفی از وسط اسم رو هم به ترتیب بنویس (نه لزوماً از اول) — مثلاً `mtp` یا `mpy` هم می‌تونه `multiply` رو پیدا کنه.

این میان‌برها به‌تنهایی کار بزرگی نمی‌کنن، ولی روی هم رفته، توی طولانی‌مدت خیلی توی سرعت کدنویسیت فرق می‌ذارن.
