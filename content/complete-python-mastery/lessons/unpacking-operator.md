## باز کردن یه پیمایش‌پذیر با `*`

قبلاً `*` رو توی چند جا دیدی: `*args` توی تعریف تابع، و list unpacking (`first, *rest = numbers`). همین عملگر یه کاربرد کلی‌تر هم داره: **باز کردن** (unpacking) هر پیمایش‌پذیری، هرجایی که لازم داری.

## چاپ اعضای یه لیست، جدا از هم

```python
numbers = [1, 2, 3]

print(numbers)
# [1, 2, 3]

print(*numbers)
# 1 2 3
```

با `*numbers`، به‌جای پاس‌دادن خود لیست به `print`، اعضاش رو **جدا جدا** به‌عنوان چندتا آرگومان پاس می‌دیم — دقیقاً همون‌جوری که `*args` توی یه تابع، آرگومان‌های جدا رو جمع می‌کنه، اینجا برعکسش عمل می‌کنیم: یه پیمایش‌پذیر رو باز می‌کنیم به آرگومان‌های جدا.

## ساختن لیست با اعضای باز شده

```python
numbers = [*range(5), *"hi"]
print(numbers)
# [0, 1, 2, 3, 4, 'h', 'i']
```

`*` روی هر پیمایش‌پذیری کار می‌کنه — نه فقط لیست. اینجا `range(5)` و رشته‌ی `"hi"` هر دو باز شدن و اعضاشون توی یه لیست جدید جمع شدن.

## ترکیب چند لیست

```python
list1 = [1, 2]
list2 = [3, 4]

combined = [*list1, *list2]
print(combined)
# [1, 2, 3, 4]
```

می‌تونی بین یا بعدشون هم چیز دیگه‌ای اضافه کنی:

```python
combined = [*list1, 100, *list2]
print(combined)
# [1, 2, 100, 3, 4]
```

## باز کردن دیکشنری با `**`

برای دیکشنری، از دو ستاره استفاده می‌کنیم — دقیقاً مثل `**kwargs`:

```python
d1 = {"x": 1}
d2 = {"x": 10, "y": 2}

combined = {**d1, **d2}
print(combined)
# {'x': 10, 'y': 2}
```

اگه یه کلید توی چندتا دیکشنری تکرار بشه (اینجا `x`)، **آخرین مقدار** برنده می‌شه — چون دیکشنری دوم بعد از اولی باز شده، مقدارش رو overwrite می‌کنه.
