## یه تابع یک‌بارمصرف

توی درس قبل، برای مرتب‌سازی سفارش‌ها بر اساس قیمت، یه تابع جدا تعریف کردیم:

```python
def sort_item(item):
    return item[1]


items.sort(key=sort_item)
```

این تابع فقط همین یه‌بار، فقط برای همین کار استفاده می‌شه. تعریف‌کردن یه تابع مستقل با `def` و یه اسم، برای همچین کار کوچیکی یه‌کم زیادیه. اینجاست که **تابع لامبدا** (lambda) به کمک میاد.

## نحو لامبدا

```python
lambda item: item[1]
```

فرمول کلی: `lambda پارامترها: عبارت`. این یه تابع بدون اسمه (anonymous function) که:
- نیازی به `def` نداره.
- اسم نمی‌خواد.
- پرانتز دور پارامترها نمی‌خواد.
- `return` نمی‌خواد — نتیجه‌ی همون عبارت، خودش مقدار بازگشتیه.

## بازنویسی مرتب‌سازی با لامبدا

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]

items.sort(key=lambda item: item[1])
print(items)
# [('Product 2', 5), ('Product 1', 10), ('Product 3', 15)]
```

دیگه نیازی به تعریف جدای `sort_item` نیست — همه‌چیز توی همون خط `sort()` نوشته شده. این دقیقاً همون نتیجه‌ی قبلیه، فقط کوتاه‌تر.

## کِی از لامبدا استفاده کنیم

لامبدا برای توابع کوچیک، **یک‌بارمصرف**، که به‌عنوان آرگومان به یه تابع دیگه (مثل `sort`) پاس داده می‌شن، عالیه. اگه یه تابع پیچیده‌ست یا قراره چندجا استفاده بشه، همون `def` معمولی خواناتره.
