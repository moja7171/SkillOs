## چالش

قبل از دیدن جواب، خودت امتحان کن:

> یه برنامه بنویس که اعداد زوج بین ۱ تا ۱۰ رو چاپ کنه (یعنی ۲، ۴، ۶، ۸)، و بعدش این پیام رو چاپ کنه: «۴ عدد زوج داریم».
>
> راهنمایی: `range` رو با ۱ و ۱۰ صدا بزن (بدون آرگومان سوم).

چند دقیقه وقت بذار و خودت بنویسش، بعد بیا ادامه رو بخون.

## قدم اول: چاپ اعداد زوج

```python
for number in range(1, 10):
    if number % 2 == 0:
        print(number)
```

خروجی:
```
2
4
6
8
```

اینجا از عملگر `%` (باقی‌مونده‌ی تقسیم) استفاده کردیم. اگه باقی‌مونده‌ی تقسیم یه عدد بر ۲ صفر باشه، یعنی زوجه.

## قدم دوم: شمردن تعدادشون

برای شمردن، یه متغیر شمارنده لازم داریم که از ۰ شروع بشه و هر بار که یه عدد زوج پیدا کردیم، یکی بهش اضافه بشه:

```python
count = 0

for number in range(1, 10):
    if number % 2 == 0:
        print(number)
        count += 1

print(f"we have {count} even numbers")
```

خروجی:
```
2
4
6
8
we have 4 even numbers
```

`count += 1` یعنی «یکی به count اضافه کن»، مخفف `count = count + 1`. چون این خط زیر همون `if` تورفتگی داره، فقط وقتی اجرا می‌شه که عدد زوج باشه.

## جمع‌بندی این بخش

با این سه چیز — `for` + `range`، `while`، و `break`/`else` — می‌تونی هر نوع تکراری که لازم داری رو بنویسی. بخش بعدی می‌ریم سراغ توابع: چطور یه تیکه کد رو بسته‌بندی کنی که بشه هر جا خواستی دوباره صداش بزنی.
