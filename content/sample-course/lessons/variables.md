## متغیر چیست؟

در پایتون متغیر یک **نام** است که به یک مقدار اشاره می‌کند. لازم نیست نوعش را اعلام کنی؛ همین که مقدار می‌دهی، ساخته می‌شود:

```python
name = "Sara"
age = 27
height = 1.68
is_student = True
```

هر کدام از این مقادیر یک **نوع (type)** دارند: `str`، `int`، `float` و `bool`. با تابع `type()` می‌توانی نوع را ببینی:

```python
print(type(age))      # <class 'int'>
print(type(height))   # <class 'float'>
```

## تبدیل نوع

پایتون نوع‌ها را خودکار با هم قاطی نمی‌کند. این خط خطا می‌دهد:

```python
print("Age: " + age)   # TypeError
```

باید صریح تبدیل کنی:

```python
print("Age: " + str(age))
total = int("42") + 8   # 50
```

## نام‌گذاری

- حروف کوچک و زیرخط: `first_name`, `total_price`
- با عدد شروع نکن، از فاصله استفاده نکن
- نام‌های داخلی پایتون مثل `list`, `str`, `sum` را به‌عنوان متغیر نگیر — تابع اصلی را پنهان می‌کنی.
