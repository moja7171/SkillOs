## گرفتن ورودی از کاربر

با `input` می‌تونی از کاربر یه چیزی بپرسی:

```python
x = input("x: ")
y = x + 1
```

> نکته: این کد رو با Code Runner اجرا نکن — اون خروجی رو توی یه پنل read-only نشون می‌ده و نمی‌تونی چیزی تایپ کنی. از ترمینال معمولی استفاده کن.

اگه این کدو اجرا کنی و مثلاً `1` وارد کنی، یه خطا می‌گیری: `TypeError`. چرا؟ چون **هرچی از `input` بیاد، همیشه رشته‌ست** — حتی اگه کاربر عدد تایپ کرده باشه! پس اون خط عملاً داره می‌گه `"1" + 1`، و پایتون نمی‌دونه یه رشته و یه عدد رو چطوری باهم جمع کنه.

می‌تونی مطمئن بشی با تابع `type`:

```python
print(type(x))   # <class 'str'>
```

## تبدیل نوع (Type Conversion)

راه‌حل ساده‌ست — قبل از جمع کردن، تبدیلش کن به عدد:

```python
x = input("x: ")
x = int(x)
y = x + 1
print(f"x is {x} and y is {y}")
```

توابع تبدیل نوع که داریم: `int`، `float`، `str`، `bool`.

## Truthy و Falsy — تنها بخش کمی گیج‌کننده‌ش

`bool` یه‌کم خاصه، چون توی پایتون هر مقداری رو می‌تونی به یه بولی تبدیل کنی، حتی اگه واقعاً `True`/`False` نباشه:

```python
print(bool(0))        # False
print(bool(1))        # True
print(bool(-1))       # True
print(bool(5))        # True
print(bool(""))       # False
print(bool("False"))  # True!
```

رشته‌ی خالی `False` می‌شه، ولی `"False"` — با اینکه معنیش یعنی «غلط» — چون یه رشته‌ی غیرخالیه، `True` می‌شه! عجیبه ولی منطقیه. قانونش خیلی ساده‌ست: فقط `0`، رشته‌ی خالی `""` و `None` (که بعداً می‌بینیمش) به `False` تبدیل می‌شن — به این‌ها می‌گیم **falsy**. هر چیز دیگه‌ای **truthy** حساب می‌شه، یعنی `True`.
