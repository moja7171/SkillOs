## اپ‌های وب

اپ‌های وب احتمالاً رایج‌ترین نوع اپلیکیشن امروزه‌ان، شاید فقط بعد از وب API. اپ‌های وب، که به‌عنوان وب‌سایت هم شناخته می‌شن، اساساً همون شکلیه که اینترنت از ابتدا کار می‌کرده.

توی یه اپ وب، یه وب‌سرور (معمولاً بیشتر از یکی) و یه مرورگر داریم. این دو تا از طریق پروتکل HTTP با هم ارتباط برقرار می‌کنن، هرچند پروتکل‌های دیگه هم می‌تونن استفاده بشن. مرورگر یه درخواست HTTP به سرور می‌فرسته و یه منبع رو می‌خواد. اون منبع، توی این حالت، یه صفحه‌ی HTML‌ـه که برمی‌گرده به مرورگر، و مرورگر اون رو برای کاربر نهایی رندر می‌کنه. تقریباً همیشه صفحه‌ی HTML از کد JavaScript برای پیاده‌سازی منطق توی مرورگر و از فایل‌های CSS برای طراحی بصری صفحه استفاده می‌کنه.

### کِی از اپ وب استفاده کنیم؟

اپ‌های وب بهترین گزینه‌ان برای:

- سیستم‌هایی که به رابط کاربری برای کاربر نهایی نیاز دارن.
- اکشن‌هایی که کاربر شروعشون می‌کنه — یعنی خودِ کاربره که درخواست انجام یه کاری رو می‌ده، مثل دیدن اطلاعات سفارش یا ذخیره‌ی نام کاربری.
- مقیاس بزرگ با تعداد زیاد کاربر و داده‌ی زیاد.
- اکشن‌های کوتاه و متمرکز، نه فرایندهای طولانی‌مدت. مثلاً اپ‌های وب گزینه‌ی خوبی برای فرایندی که باید میلیاردها عدد رو پردازش کنه و هوش تجاری تولید کنه نیستن — برای این کار، انواع دیگه‌ای از اپلیکیشن وجود داره.

همون‌طور که گفتیم، اپ‌های وب توی مدل درخواست-پاسخ (request-response) کار می‌کنن، که شاید مهم‌ترین جنبه‌شونه. قاعده‌ی سرانگشتی: اگه سیستمی که روش کار می‌کنی رو می‌شه به‌عنوان یه اپلیکیشن درخواست-پاسخ توصیف کرد، احتمالاً داری با یه اپ وب سروکار داری.
