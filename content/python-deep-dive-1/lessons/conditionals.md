## if / elif / else

```python
a = 15

if a < 5:
    print("a < 5")
elif a < 10:
    print("5 <= a < 10")
else:
    print("a >= 10")
```

پایتون `switch` ندارد (تا نسخه‌ی ۳.۱۰ که `match` اضافه شد، آن هم چیز دیگری است). زنجیره‌ی `elif` همان کار را می‌کند: شرط‌ها **به ترتیب** چک می‌شوند و اولین شرط درست، بقیه را کنار می‌زند. پس ترتیب مهم است — اگر `a < 10` را قبل از `a < 5` بنویسی، شاخه‌ی دوم هیچ‌وقت اجرا نمی‌شود.

بلوک‌ها با **تورفتگی** مشخص می‌شوند، نه با `{}`. چهار فاصله استاندارد است. بلوک خالی مجاز نیست؛ اگر فعلاً چیزی نداری بنویسی، `pass` بگذار.

## عبارت شرطی (ternary)

وقتی فقط می‌خواهی **یک مقدار** را بر اساس شرط انتخاب کنی، به‌جای چهار خط if/else یک عبارت بنویس:

```python
label = "small" if a < 10 else "large"
```

ساختارش `X if condition else Y` است — اول مقدار حالت درست، بعد شرط، بعد مقدار حالت غلط. این یک **عبارت** است، پس می‌تواند داخل فراخوانی تابع، f-string یا `return` بیاید. برای منطق پیچیده یا چند شاخه، به if/elif معمولی برگرد؛ ternary تودرتو خواندنی نیست.

## چند نکته‌ی ریز

- شرط لازم نیست `True`/`False` واقعی باشد؛ هر مقداری «truthy» یا «falsy» است (لیست خالی، `0`، `None`، `""` همه falsy هستند). بخش Booleanها دقیقاً همین را باز می‌کند.
- مقایسه‌ها زنجیره می‌شوند: `5 <= a < 10` همان `5 <= a and a < 10` است.
