## یه میان‌بر باحال برای اجرا

خسته شدی هر بار ترمینال باز کنی و دستی `python app.py` بزنی؟ افزونه‌ی **Code Runner** رو از تب Extensions نصب کن. از این به بعد فقط `Ctrl+Alt+N` بزن، فایل اجرا می‌شه و خروجی همون‌جا میاد.

> یادت نره قبل از اجرا فایل رو ذخیره کنی — وگرنه Code Runner نتیجه‌ی نسخه‌ی قدیمی فایل رو نشونت می‌ده و گیج می‌شی که چرا خروجی عوض نشد.

## اگه مک داری

روی مک، Code Runner به‌صورت پیش‌فرض از دستور `python` استفاده می‌کنه که همون پایتون ۲ قدیمیه. برای درستش کردن:

۱. از Command Palette برو «Preferences: Open User Settings (JSON)».
۲. کلید `code-runner.executorMap` رو اضافه کن و مقدار پایتون رو بذار `python3`.

روی ویندوز نیازی به این کار نیست چون `python` همون پایتون ۳ ـه.
