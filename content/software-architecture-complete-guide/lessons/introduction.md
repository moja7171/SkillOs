## مقدمه‌ای بر فرایند طراحی معماری

به بخش فرایند معماری خوش اومدی. توی این بخش درباره‌ی فرایند کارِ معمار حرف می‌زنیم. برای اینکه معماری تا حد ممکن مفید باشه و بیشترین ارزش رو برای مشتری بیاره، معمار باید یه نقشه‌راه واضح رو دنبال کنه که در نهایت به یه معماریِ کاربردی و سنجیده می‌رسه — معماری‌ای که تضمین می‌کنه سیستم سریع، امن، قابل‌اطمینان و قابل‌نگهداریه.

توی این بخش، هر قدم از این فرایند رو مرور می‌کنیم و اهمیتش رو توضیح می‌دیم. توی بخش‌های بعدی، عمیق‌تر توی هر قدم فرو می‌ریم و می‌بینیم دقیقاً چی باید انجام بشه.

### قدم‌های فرایند معماری

۱. نیازمندی‌های سیستم رو بفهم
۲. نیازمندی‌های غیرکارکردی رو بفهم
۳. اجزا رو نقشه‌برداری کن
۴. پشته‌ی فناوری رو انتخاب کن
۵. معماری رو طراحی کن
۶. سند معماری رو بنویس
۷. از تیم توسعه پشتیبانی کن

بیا درباره‌ی هر کدوم از این قدم‌ها حرف بزنیم.
