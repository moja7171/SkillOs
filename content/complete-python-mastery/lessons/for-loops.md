## چرا حلقه؟

فرض کن می‌خوای یه پیام رو برای یه کاربر بفرستی، و اگه نرسید، بازم امتحان کنی — مثلاً تا ۳ بار. اگه بخوای این کارو بدون حلقه بنویسی، باید همون چند خط کد رو ۳ بار کپی کنی. زشته و دردسرسازه. برای همینه که از **حلقه** (loop) استفاده می‌کنیم — تا یه کار رو چندبار تکرار کنیم، بدون تکرار کد.

## حلقه‌ی `for`

```python
for number in range(3):
    print("attempt")
```

خروجی:
```
attempt
attempt
attempt
```

بعد از `for`، یه متغیر می‌ذاری (اینجا `number`) که توی هر تکرار یه مقدار جدید می‌گیره، بعد `in`، بعد چیزی که روش تکرار می‌کنی. `range(3)` یعنی «۳ بار». مثل `if`، این خط هم با `:` تموم می‌شه و بدنه‌ی حلقه تورفتگی داره.

## خود `number` چیه؟

```python
for number in range(3):
    print("attempt", number)
```

خروجی:
```
attempt 0
attempt 1
attempt 2
```

`number` توی هر تکرار یه عدد صحیح متفاوته: تکرار اول ۰، دومی ۱، سومی ۲. یعنی **از صفر شروع می‌شه**، نه از یک — یه نکته‌ی مهم که باید بهش عادت کنی.

## چند شکل `range`

```python
range(3)        # 0, 1, 2
range(1, 4)     # 1, 2, 3          -- starts at 1, stops before 4
range(1, 10, 2) # 1, 3, 5, 7, 9    -- step of 2
```

- یه آرگومان: از ۰ تا قبل از اون عدد.
- دو آرگومان: از عدد اول تا قبل از عدد دوم.
- سه آرگومان: عدد سوم گامه (step) — هر بار چقدر جلو بره.

در هر حالت، **عدد آخر جزو نتیجه نیست** — دقیقاً همون رفتاری که توی برش رشته‌ها (`[start:end]`) هم دیدی.

## یه ترفند کوچیک

یه رشته رو می‌تونی با ضرب توی یه عدد، همون تعداد تکرار کنی — مثلاً `"-" * 3` می‌شه `"---"`. با این ترفند، می‌شه توی هر تکرار یه چیز رو بسته به شماره‌ی همون تکرار «رسم» کرد:

```python
for number in range(1, 4):
    print(f"attempt {'.' * number}")
```

خروجی:
```
attempt .
attempt ..
attempt ...
```

هر بار تعداد نقطه‌ها برابر شماره‌ی همون تکراره. حلقه‌ی `for` همراه با `range` یکی از پرکاربردترین ابزارهاییه که توی پایتون همیشه ازش استفاده می‌کنی.
