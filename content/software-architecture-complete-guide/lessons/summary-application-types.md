## جمع‌بندی

رایج‌ترین انواع اپلیکیشنی که به‌عنوان معمار باهاشون روبه‌رو می‌شی رو مرور کردیم. با این حال، امروز توی عصر کلاود، انواع خیلی بیشتری از اپلیکیشن وجود داره. مثلاً یکی از داغ‌ترین روندهای امروزی، Function as a Service‌ـه — مثل AWS Lambda یا Azure Functions — که به توسعه‌دهنده اجازه می‌ده یه تکه کد کوتاه و متمرکز بنویسه و نگران مقیاس‌پذیری یا SLA سرورها نباشه. اپلیکیشن‌های ساخته‌شده روی این توابع، نه اپ وب هستن نه وب API، و یه نوع جدید از اپلیکیشن رو نمایندگی می‌کنن.

ولی همچنان، بیشتر اپلیکیشن‌های امروزی توی همون دسته‌بندی‌هایی که بررسی کردیم جا می‌گیرن. یکی از اولین کارهایی که موقع شروع کار روی یه سیستم داری، تعیین اینه که کدوم نوع اپلیکیشن براش مناسب‌تره. اغلب یه سیستم از بیشتر از یه اپلیکیشن تشکیل شده و خودت رو با ترکیب انواع مختلف توی یه سیستم واحد پیدا می‌کنی.

مثلاً خیلی از اپ‌های وب، علاوه بر اپلیکیشن اصلی، یه سرویس هم دارن که مداوم اجرا می‌شه و کارهای نگهداری رو انجام می‌ده — مثل حذف رکوردهای قدیمی داده یا پایش فرایندهای مختلف. این کاملاً رایجه و احتمالاً توی کارت با این نوع سیستم‌ها روبه‌رو می‌شی.
