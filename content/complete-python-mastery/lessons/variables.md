## متغیر یعنی چی؟

فکرش رو بکن: یه چیزی می‌خوای توی حافظه‌ی کامپیوتر نگه‌داری — مثلاً تعداد دانشجوهای یه کلاس. به این کار می‌گیم **متغیر (variable)**:

```python
students_count = 1000
```

وقتی این خط اجرا می‌شه، پایتون یه جا توی حافظه باز می‌کنه، عدد ۱۰۰۰ رو توش می‌ذاره و اسم `students_count` رو مثل یه برچسب می‌چسبونه بهش. از این به بعد هرجای برنامه که اسمشو بیاری، دقیقاً می‌ری سراغ همون مقدار:

```python
print(students_count)   # 1000
```

## چهارتا نوع داده‌ی پایه

پایتون چهارتا نوع داده‌ی پایه داره که همه‌جا باهاشون سروکار داری:

```python
students_count = 1000       # int
rating = 4.99                # float
is_published = True          # bool
course_name = "Python programming"   # str
```

`int` عدد صحیحه، `float` عدد اعشاری، `bool` یعنی درست یا غلط، و `str` یعنی رشته (متن).

> نکته‌ی مهم: پایتون به کوچیک/بزرگ بودن حروف حساسه. `True` و `False` درسته، `true` یا `false` خطا می‌ده.

و متن همیشه باید داخل کوتیشن باشه، وگرنه پایتون فکر می‌کنه داری اسم یه متغیر دیگه رو می‌گی.
