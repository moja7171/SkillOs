## مجموعه‌ای بدون تکرار

**مجموعه** (set) یه ساختار داده‌ست که هیچ عضو تکراری قبول نمی‌کنه. اگه یه لیست با موارد تکراری داری و بخوای فقط موارد یکتا رو نگه داری، کافیه به `set` تبدیلش کنی:

```python
numbers = [1, 1, 2, 3, 3]

unique = set(numbers)
print(unique)
# {1, 2, 3}
```

مجموعه با آکولاد نشون داده می‌شه — شبیه دیکشنری، ولی بدون کلید، فقط مقدار.

## ساخت مستقیم و عملیات پایه

```python
second = {1, 4}

second.add(5)
second.remove(4)

print(len(second))
# 2
```

`add` عضو جدید اضافه می‌کنه، `remove` حذف می‌کنه، `len` تعداد اعضا رو می‌ده — همه شبیه لیست.

## جایی که مجموعه واقعاً می‌درخشه: عملیات ریاضی

```python
first = {1, 2, 3, 4}
second = {1, 5}

print(first | second)   # union: {1, 2, 3, 4, 5}
print(first & second)   # intersection: {1}
print(first - second)   # difference: {2, 3, 4}
print(first ^ second)   # symmetric difference: {2, 3, 4, 5}
```

| عملگر | اسم | معنی |
|---|---|---|
| `\|` | اجتماع (union) | همه‌ی اعضایی که توی هرکدوم هستن |
| `&` | اشتراک (intersection) | فقط اعضایی که توی هر دو هستن |
| `-` | تفاضل (difference) | اعضای مجموعه‌ی اول، منهای اونایی که توی دومی هم هستن |
| `^` | تفاضل متقارن | اعضایی که فقط توی یکی از دوتا هستن، نه هر دو |

## بدون ترتیب، بدون ایندکس

```python
first = {1, 2, 3}
print(first[0])
# TypeError: 'set' object is not subscriptable
```

مجموعه **مرتب نیست** — اعضاش دنباله ندارن، پس نمی‌شه با ایندکس بهشون دسترسی داشت. اگه به ترتیب یا دسترسی با ایندکس نیاز داری، از لیست استفاده کن. برای چک‌کردن وجود یه عضو، از `in` استفاده کن:

```python
if 1 in first:
    print("yes")
```

## جمع‌بندی

از مجموعه استفاده کن وقتی: (۱) نمی‌خوای عضو تکراری داشته باشی، یا (۲) نیاز به عملیات ریاضی (اجتماع، اشتراک، تفاضل) روی چند دسته از داده داری.
