## ویرایشگر کد یا IDE؟

برای نوشتن کد پایتون دو راه داری:

- **ویرایشگر کد (code editor)**: مثل VS Code، Atom یا Sublime — سبک و ساده.
- **IDE** (مخفف Integrated Development Environment): یه ویرایشگر با کلی امکانات اضافه از قبل توش نصب شده، مثل تکمیل خودکار، دیباگ، تست. معروف‌ترینش برای پایتون، PyCharm ـه.

فرقشون چیه؟ IDE از اول «باتری‌کامل» ـه — همه‌چی توش هست. ویرایشگر کد سبک‌تره و هر چی لازم داری رو با افزونه (extension) اضافه می‌کنی.

ما توی این دوره از **VS Code** استفاده می‌کنیم؛ توی درس بعدی با یه افزونه تبدیلش می‌کنیم به یه IDE کامل برای پایتون. الان برو [code.visualstudio.com](https://code.visualstudio.com) و آخرین نسخه رو دانلود و نصب کن.
