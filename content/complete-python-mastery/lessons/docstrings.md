## چرا مستندسازی مهمه

وقتی یه ماژول کتابخانه‌ی استاندارد رو import می‌کنی (مثلاً `math`)، ویرایشگر کد یه راهنمای کوچیک (IntelliSense) موقع تایپ‌کردن نشونت می‌ده — توضیح اینکه هر تابع چیکار می‌کنه، چه پارامترهایی می‌گیره. این توضیحات از یه چیز به اسم **docstring** میان.

اگه خودت یه پکیج بسازی و منتشرش کنی، بدون مستندسازی، هیچ‌کس نمی‌دونه توابعت چیکار می‌کنن یا چطور ازشون استفاده کنه.

## docstring چیه

**docstring** یه رشته‌ی سه‌کوتیشنی (`"""..."""`) هست که بلافاصله بعد از تعریف یه ماژول، کلاس یا تابع میاد. با کامنت (`#`) فرق داره:

- **کامنت**: توضیح می‌ده **چرا** یه کار به یه شکل خاص انجام شده (برای کسی که کد رو می‌خونه).
- **docstring**: توضیح می‌ده یه تابع/کلاس/ماژول **چیکار می‌کنه** (برای کسی که ازش استفاده می‌کنه، حتی بدون خوندن کد داخلش).

## docstring ساده (یه‌خطی)

برای موارد ساده، یه خط کافیه:

```python
def convert():
    """Convert the given PDF to text."""
    pass
```

## docstring چندخطی

برای توابعی که پارامتر و مقدار بازگشتی دارن، از یه فرمت استاندارد استفاده می‌کنیم: یه خلاصه‌ی کوتاه، یه خط خالی، بعد توضیح پارامترها و مقدار بازگشتی:

```python
def convert(path):
    """Convert the given PDF to text.

    Parameters:
        path (str): The path to a PDF file.

    Returns:
        str: The content of the PDF file as text.
    """
    pass
```

## مستندسازی یه ماژول کامل

وقتی یه ماژول رو برای استفاده‌ی دیگران منتشر می‌کنی، باید **همه‌چیز** رو مستند کنی: خودِ ماژول، هر کلاس، و هر تابع توش.

```python
"""This module provides functions to convert a PDF to text."""


class Converter:
    """A simple converter for converting PDFs to text."""

    def convert(self, path):
        """Convert the given PDF to text.

        Parameters:
            path (str): The path to a PDF file.

        Returns:
            str: The content of the PDF file as text.
        """
        pass
```

docstring ماژول، بالای همه‌چیز، قبل از هر `import` یا تعریف کلاس/تابع میاد. docstring کلاس هم دقیقاً همون‌جایی میاد که docstring یه تابع می‌اومد — بلافاصله بعد از خط `class`.

## جمع‌بندی

docstring یعنی مستندسازی **چیستیِ** یه تابع/کلاس/ماژول، به‌شکلی که ابزارهایی مثل IntelliSense بتونن نشونش بدن. اگه قراره کدت رو دیگران استفاده کنن (حتی خودِ آینده‌ات)، مستندسازی کامل — نه فقط برای توابع ساده — یه سرمایه‌گذاری کوچیکه که وقت زیادی رو بعداً صرفه‌جویی می‌کنه.
