## نوع‌دهی ایستا (static): Java، C++، C#، Swift

```java
String myVar = "hello";
```

سه چیز اینجا هست: نام متغیر، **نوع داده‌ای که به نام چسبیده** (`String`)، و مقدار. شیء `"hello"` در حافظه ساخته می‌شود و `myVar` به آن اشاره می‌کند — تا اینجا مثل پایتون. تفاوت این است که **نوع به خود متغیر** تعلق دارد:

```java
myVar = 10;      // error: myVar is of type String
myVar = "abc";   // correct
```

## نوع‌دهی پویا (dynamic): پایتون

```python
my_var = "hello"
```

`my_var` هیچ نوعی ندارد. فقط یک ارجاع است — به شیئی که *فعلاً* یک `str` است. اگر بعداً بنویسی `my_var = 10`، پایتون یک شیء int می‌سازد و ارجاع `my_var` را به آن عوض می‌کند. کاملاً مجاز.

ظاهراً «نوع my_var عوض شد»، ولی `my_var` هیچ‌وقت نوعی نداشت که عوض شود. چیزی که عوض شد، **نوع شیئی است که my_var به آن اشاره می‌کند**.

## `type()` نوع شیء را می‌گوید، نه نوع متغیر

```python
>>> a = "hello"
>>> type(a)
<class 'str'>
>>> a = 10
>>> type(a)
<class 'int'>
>>> a = lambda x: x ** 2
>>> a(2)
4
>>> type(a)
<class 'function'>
>>> a = 3 + 4j
>>> type(a)
<class 'complex'>
```

هر بار فقط ارجاع `a` به شیء دیگری رفته و `type(a)` نوع *آن شیء* را برگردانده. این تمام معنی «dynamically typed» است.

(آنچه در بخش مرور سریع درباره‌ی annotationها دیدی — `a: int` — این وضعیت را عوض نمی‌کند؛ annotation فقط مستندسازی است و پایتون آن را اجبار نمی‌کند.)
