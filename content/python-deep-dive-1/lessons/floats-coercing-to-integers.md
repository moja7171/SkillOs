## چهار راه، همه با از دست دادن داده

تبدیل `10.4` به عدد صحیح یعنی ۱۰ یا ۱۱ — هر کدام را انتخاب کنی، اطلاعات از دست می‌رود. سؤال این است که **چطور** می‌خواهی از دست بدهی: truncation، floor، ceiling، یا rounding (درس بعد). بستگی به مسئله دارد: اگر `10.4` تعداد دفعات لازم برای تمام شدن کاری است، ۱۰ کافی نیست و ۱۱ می‌خواهی.

## Truncation: فقط قسمت صحیح

هر چه بعد از ممیز هست دور ریخته می‌شود — برای مثبت و منفی به یک شکل:

```python
from math import trunc
trunc(10.3), trunc(10.5), trunc(10.9)      # 10, 10, 10
trunc(-10.3), trunc(-10.5), trunc(-10.9)   # -10, -10, -10
```

سازنده‌ی `int` با float دقیقاً همین کار را می‌کند: `int(10.9)` → `10`، `int(-10.9)` → `-10`. پس اگر نمی‌خواهی `math` را import کنی، `int()` همان trunc است.

## Floor: بزرگ‌ترین صحیحِ ≤ x

```python
from math import floor
floor(10.3), floor(10.5), floor(10.9)      # 10, 10, 10
floor(-10.3), floor(-10.5), floor(-10.9)   # -11, -11, -11  ← نه −10
```

روی محور، `−10.4` بین `−11` و `−10` است؛ بزرگ‌ترین صحیح کوچک‌تر از آن `−11`. **برای اعداد مثبت floor و trunc یکی‌اند؛ برای منفی‌ها نه.** بازه: هر عدد در `[10, 11)` floorش ۱۰ است، هر عدد در `[−11, −10)` floorش −۱۱.

یادآوری از درس عملیات: `a // b` دقیقاً `floor(a / b)` است — برای همین «floor division» — و همین تعریف، معنی `%` را هم تعیین می‌کند تا `a == b*(a//b) + a%b` برقرار بماند.

## Ceiling: کوچک‌ترین صحیحِ ≥ x

```python
from math import ceil
ceil(10.4), ceil(10.5), ceil(10.9)         # 11, 11, 11
ceil(-10.4), ceil(-10.5), ceil(-10.9)      # -10, -10, -10
```

قرینه‌ی floor: هر عدد در `(10, 11]` ceilش ۱۱ است. برای منفی‌ها «بالاتر» یعنی به سمت صفر: `ceil(−10.4) = −10`.

## خلاصه

| x | trunc / int() | floor | ceil |
|---|---|---|---|
| 10.4 | 10 | 10 | 11 |
| 10.9 | 10 | 10 | 11 |
| −10.4 | −10 | −11 | −10 |
| −10.9 | −10 | −11 | −10 |

به بازه‌های باز/بسته دقت کن: خود عدد صحیح، floor و ceil خودش است (`floor(11) == ceil(11) == 11`).
