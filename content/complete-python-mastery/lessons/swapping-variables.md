## راه معمول: یه متغیر کمکی

یه تمرین کلاسیک برای تازه‌کارها: جابه‌جاکردن مقدار دو تا متغیر. راه پایه‌ش نیاز به یه متغیر سوم داره:

```python
x = 10
y = 11

z = x       # z is a backup copy of x
x = y       # x takes y's value
y = z       # y takes x's old value (saved in z)

print(x, y)
# 11 10
```

## راه پایتونی: بدون متغیر کمکی

پایتون یه راه خیلی کوتاه‌تر داره — بدون نیاز به هیچ متغیر سومی:

```python
x = 10
y = 11

x, y = y, x

print(x, y)
# 11 10
```

## زیر پوسته چه اتفاقی می‌افته؟

`x, y = y, x` در واقع دو مرحله داره:

1. سمت راست (`y, x`) یه **تاپل** می‌سازه — همون‌طور که توی درس قبل دیدی، پرانتز لازم نیست، فقط کاما کافیه. اینجا مقدار فعلی `y` و `x` توی یه تاپل جمع می‌شن.
2. سمت چپ (`x, y`)، همون تاپل رو **باز می‌کنه** (unpacking) — دقیقاً همون کاری که با لیست‌ها هم می‌کردیم.

## همین ترفند برای مقداردهی چندتایی

همین نحو رو می‌شه برای تعریف چند متغیر توی یه خط هم استفاده کرد:

```python
a, b = 1, 2
print(a, b)
# 1 2
```

اینجا هم دقیقاً همون اتفاق می‌افته: `1, 2` یه تاپل می‌سازه، `a, b` بازش می‌کنه.
