## اجرای سریع‌تر با Code Runner

به‌جای باز کردن ترمینال و تایپ دستی `python app.py`، افزونه‌ی **Code Runner** را از تب Extensions نصب کن. بعد از نصب، با کلید میان‌بر `Ctrl+Alt+N` فایل باز اجرا می‌شود و خروجی همان‌جا نمایش داده می‌شود.

> قبل از اجرا حتماً فایل را ذخیره کن؛ وگرنه Code Runner نتیجه‌ی نسخه‌ی قبلی فایل را نشان می‌دهد.

## تنظیم برای مک

روی مک، Code Runner به‌صورت پیش‌فرض از دستور `python` استفاده می‌کند که به پایتون ۲ اشاره دارد. برای اصلاحش:

۱. از Command Palette گزینه‌ی «Preferences: Open User Settings (JSON)» را باز کن.
۲. کلید `code-runner.executorMap` را اضافه کن و مقدار پایتون را به `python3` تغییر بده.

روی ویندوز نیازی به این تغییر نیست، چون `python` همان پایتون ۳ است.
