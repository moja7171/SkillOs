## مفسر پایتون چیه؟

اون محیطی که با تایپ `python` یا `python3` باز می‌شه، اسمش **مفسر پایتون (interpreter)** ـه — یه برنامه که کد پایتون رو می‌خونه و اجرا می‌کنه. می‌تونی کدت رو توی یه فایل بنویسی و بدی بهش، یا مستقیم همین‌جا توی همین محیط تایپ کنی و ببینی چی می‌شه.

## عبارت (Expression)

هر تکه‌کدی که یه مقدار تولید کنه، بهش می‌گیم **عبارت (expression)**. مثلاً:

```python
>>> 2 + 2
4
```

مقایسه هم یه جور عبارته؛ فقط نتیجه‌ش `True` یا `False` می‌شه:

```python
>>> 2 > 1
True
>>> 2 > 5
False
```

## وقتی چیزی رو ناقص می‌نویسی

اگه یه عبارت رو نصفه ول کنی، مثلاً:

```python
>>> 2 >
```

مفسر بهت می‌گه **syntax error** — یعنی خطای نحوی، یعنی گرامرت خرابه. دقیقاً مثل وقتی یه جمله رو نصفه‌کاره ول می‌کنی و طرف مقابل نمی‌فهمه چی می‌گی؛ مفسر پایتون هم همین‌جوری گیج می‌شه.

> این محیط تعاملی برای امتحان سریع یه تکه‌کد خیلی خوبه، ولی برای ساختن یه برنامه‌ی واقعی به یه ویرایشگر کد نیاز داری — دقیقاً موضوع درس بعدی.
