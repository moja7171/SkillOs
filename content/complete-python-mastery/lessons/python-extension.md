## افزونه‌ی Python

با نصب افزونه‌ی رسمی **Python** در VS Code، این ویرایشگر به یک IDE کامل تبدیل می‌شود. این افزونه این امکانات را اضافه می‌کند:

- **Linting**: تحلیل کد برای پیدا کردن خطاهای احتمالی، پیش از اجرا.
- **Debugging**: پیدا کردن و رفع خطا با اجرای گام‌به‌گام کد.
- **تکمیل خودکار (autocompletion)**: نوشتن سریع‌تر کد بدون تایپ کامل هر کاراکتر.
- **فرمت‌بندی کد**: مرتب و خوانا کردن خودکار کد.
- **تست واحد (unit testing)**: نوشتن و اجرای خودکار تست برای کد.
- **قطعه‌کدهای آماده (snippets)**: بلوک‌های کد آماده که سریع تولید می‌شوند.

نگران حفظ‌کردن همه‌ی این‌ها نباش؛ هرکدام را در طول دوره با جزئیات می‌بینی.

## نصب

از تب Extensions در VS Code، دنبال «Python» بگرد و نصبش کن (نیاز به Reload دارد). بعد از نصب، پایین‌سمت‌چپ VS Code باید نسخه‌ی پایتون فعال نمایش داده شود — مطمئن شو پایتون ۳ انتخاب شده باشد (نه ۲).

> نسخه‌ی امروزیِ افزونه‌ی Python بیشتر این امکانات (از جمله لینتر پیش‌فرض) را به‌صورت داخلی و بدون نیاز به نصب دستی ابزار جدا فراهم می‌کند؛ روند دقیق نصب ممکن است با چیزی که در ویدیو می‌بینی کمی فرق داشته باشد، ولی مفهوم و هدف همان است.
