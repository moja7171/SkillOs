## نوع نتیجه‌ی هر عملگر

`+`, `-`, `*`, `**` روی دو int همیشه int می‌دهند. **تقسیم `/` همیشه float می‌دهد** — حتی وقتی نتیجه رند باشد:

```python
type(3 + 4)     # int
type(3 ** 6)    # int
type(2 / 3)     # float   (0.666…)
type(10 / 2)    # float!  → 5.0
```

## تقسیم صحیح و باقی‌مانده: `//` و `%`

از تقسیم طولانی دبستان: `155 ÷ 4 = 38` باقی‌مانده `3`، یعنی `155 = 4 × 38 + 3`. پایتون دو عملگر برای این دو عدد دارد:

- `155 // 4` → `38` — **floor division** (div)
- `155 % 4` → `3` — **modulo** (mod)

و همیشه این معادله برقرار است — این *تعریف* این دو عملگر است و در ادامه بارها به آن برمی‌گردیم:

```
n == d * (n // d) + (n % d)
```

## floor یعنی چه؟ (نه truncation)

floor یک عدد حقیقی = **بزرگ‌ترین عدد صحیح کوچک‌تر یا مساوی آن**.

```python
import math
math.floor(3.14)    #  3
math.floor(1.9999)  #  1
math.floor(2)       #  2
math.floor(-3.1)    # -4   ← not -3!
```

روی محور اعداد، `−3.1` بین `−4` و `−3` است؛ بزرگ‌ترین صحیحِ *کوچک‌تر* از آن `−4` است. **بریدن قسمت اعشاری (truncation)** برای اعداد مثبت همان floor است، برای منفی‌ها نه:

```python
math.trunc(-2.0625)   # -2
math.floor(-2.0625)   # -3
-33 // 16             # -3   (floor)
```

پس `a // b` = floor(a / b)، نه قسمت صحیح `a / b`.

(مدرس یک پیش‌نمایش هم می‌دهد: `math.floor(-3.000000000000001)` می‌شود `−4` ولی با چند صفر بیشتر می‌شود `−3` — دقت محدود float. در درس‌های float باز می‌شود.)

## اعداد منفی و mod

چون `//` floor است، `%` باید طوری انتخاب شود که معادله برقرار بماند — و نتیجه‌اش این است که **`%` علامت مخرج را می‌گیرد**:

| a | b | a / b | a // b | a % b | بررسی `b*(a//b) + a%b` |
|---|---|---|---|---|---|
| 13 | 4 | 3.25 | 3 | 1 | 4·3 + 1 = 13 ✓ |
| −13 | 4 | −3.25 | −4 | 3 | 4·(−4) + 3 = −13 ✓ |
| 13 | −4 | −3.25 | −4 | −3 | −4·(−4) − 3 = 13 ✓ |
| −13 | −4 | 3.25 | 3 | −1 | −4·3 − 1 = −13 ✓ |

`−13 % 4` برابر `3` است، نه `−1`. mod «باقی‌مانده‌ی تقسیم طولانی» نیست؛ عددی است که معادله را درست نگه می‌دارد.

```python
a, b = -13, 4
print(f"{a}/{b} = {a/b}")       # -3.25
print(f"{a}//{b} = {a//b}")     # -4
print(f"{a}%{b} = {a%b}")       # 3
print(a == b * (a // b) + a % b)   # True
```
