## چندتا تابع کاربردی

```python
print(round(2.9))     # 3
print(abs(-2.9))       # 2.9
```

`round` گرد می‌کنه، `abs` قدر مطلقه (همیشه مثبت برمی‌گردونه). همین، این دوتا تقریباً همه‌ی توابع آماده‌ای هستن که پایتون خودش داره. اگه بخوای محاسبات ریاضیِ پیچیده‌تر انجام بدی، باید سراغ یه **ماژول (module)** بری — یعنی یه فایل جدا پر از کد آماده که یکی دیگه از قبل نوشته.

## ماژول math

```python
import math

print(math.ceil(2.2))   # 3
```

این گرد به بالا می‌کنه. اول باید `import math` بنویسی تا این ماژول در دسترست باشه. بعدش `math` مثل یه آبجکت می‌شه که کلی متد داره — با نقطه بهشون دسترسی داری، همون‌جوری که با متدهای رشته کار کردیم.

ماژول math کلی تابع دیگه هم داره (`math.floor`، `math.sqrt`، `math.copysign` و خیلیای دیگه). لیست کاملشو با یه سرچ «python 3 math module» پیدا می‌کنی — یه گشتی توی مستنداتش بزن و چندتاشونو امتحان کن، ضرر نداره!
