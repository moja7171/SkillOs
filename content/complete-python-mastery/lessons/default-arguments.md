## اختیاری‌کردن یه پارامتر

توی درس قبل گفتیم همه‌ی پارامترها به‌طور پیش‌فرض اجباری‌ان. حالا فرض کن بیشتر وقت‌ها می‌خوای `increment` عدد رو با ۱ افزایش بده، و دلت نمی‌خواد هر بار `by=1` رو تکرار کنی:

```python
def increment(number, by=1):
    return number + by


print(increment(2))       # 3
print(increment(2, 5))    # 7
```

با گذاشتن `=1` جلوی پارامتر `by` توی تعریف تابع، بهش یه **مقدار پیش‌فرض** (default value) دادیم. حالا اگه موقع صدازدن تابع آرگومانی براش ندی، همون مقدار پیش‌فرض استفاده می‌شه. اگه بدی، همون مقداری که خودت دادی جایگزینش می‌شه.

## یه قانون مهم

پارامترهای اختیاری (که مقدار پیش‌فرض دارن) باید **بعد از** پارامترهای اجباری بیان:

```python
def increment(number, by=1):   # fine
    ...

def increment(by=1, number):   # SyntaxError!
    ...
```

منطقش اینه: وقتی تابع رو صدا می‌زنی، پایتون آرگومان‌ها رو به‌ترتیب به پارامترها نسبت می‌ده. اگه پارامتر اختیاری اول بیاد، پایتون نمی‌دونه آرگومان بعدی برای کدوم پارامتره.
