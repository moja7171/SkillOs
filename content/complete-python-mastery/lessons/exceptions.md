## وقتی یه چیزی اشتباه پیش می‌ره

توی هر برنامه‌ای، ممکنه چیزی خراب بشه: یه فایل وجود نداشته باشه، کاربر یه ورودی نامعتبر بده، یا یه منبع خارجی در دسترس نباشه. وقتی همچین اتفاقی می‌افته، پایتون برنامه رو متوقف می‌کنه و یه پیام خطا نشون می‌ده. به این نوع خطا می‌گیم **استثنا** (exception).

## یه مثال: دسترسی به ایندکس نامعتبر

```python
numbers = [1, 2]
print(numbers[2])
```

خروجی:
```
IndexError: list index out of range
```

می‌گیم این خط یه **استثنا صادر کرده** (threw an exception) — از نوع `IndexError`. این یه اشتباه برنامه‌نویسه: لیست فقط دو عضو داره (ایندکس ۰ و ۱)، ولی داریم دنبال ایندکس ۲ می‌گردیم.

## یه مثال دیگه: ورودی نامعتبر کاربر

```python
age = int(input("Age: "))
print(age)
```

اگه کاربر به‌جای عدد، یه چیز دیگه (مثلاً `"a"`) تایپ کنه:

```
ValueError: invalid literal for int() with base 10: 'a'
```

این‌بار اشتباه از خود برنامه‌نویس نیست — از **دیتای بد** میاد (ورودی کاربر). ولی نتیجه یکیه: برنامه کرش می‌کنه.

## وظیفه‌ی تو به‌عنوان برنامه‌نویس

هر دو مثال بالا، بدون هیچ محافظتی، برنامه رو کاملاً متوقف می‌کنن. وظیفه‌ی توئه که به‌جای کرش‌کردن، یه پیام خطای مناسب و قابل‌فهم به کاربر نشون بدی — مثلاً «این عدد معتبر نیست» به‌جای یه پیام فنیِ گیج‌کننده. توی درس بعدی می‌بینیم چطور.
