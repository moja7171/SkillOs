## یه تابع ساده

```python
def increment(number, by):
    return number + by


result = increment(2, 1)
print(result)
```

خروجی:
```
3
```

چون `increment` فقط یه‌جا استفاده شده، می‌تونیم متغیر واسط `result` رو حذف کنیم و مستقیم توی `print` صداش بزنیم:

```python
print(increment(2, 1))
```

نتیجه دقیقاً همونه.

## مشکل خوانایی

`increment(2, 1)` رو نگاه کن — اگه کسی این خط رو بدون دیدن تعریف تابع بخونه، معلوم نیست `1` دقیقاً چه نقشی داره. اینجاست که **آرگومان کلیدی** (keyword argument) به کمک میاد:

```python
print(increment(2, by=1))
```

با نوشتن `by=1` به‌جای فقط `1`، اسم پارامتر رو جلوی مقدارش می‌ذاریم. حالا این خط تقریباً مثل زبان محاوره خونده می‌شه: «۲ رو با ۱ تا افزایش بده».

## کِی به‌کارش ببریم

وقتی یه تابع چند تا آرگومان داره و از روی مقادیرشون معلوم نیست هرکدوم چه نقشی دارن، استفاده از آرگومان‌های کلیدی کد رو خیلی خواناتر می‌کنه — مخصوصاً برای پارامترهایی که مقدارشون (مثل عدد یا بولی) به‌تنهایی گویا نیست.
