## یه مجموعه از جفت‌های کلید-مقدار

**دیکشنری** (dictionary) یه ساختار داده‌ست که هر مقدار رو زیر یه **کلید** نگه می‌داره — دقیقاً مثل دفترچه‌تلفن: اسم یه نفر (کلید) رو می‌گیری، شماره‌ش (مقدار) رو پیدا می‌کنی.

## ساخت دیکشنری

```python
point = {"x": 1, "y": 2}
```

یه راه دیگه هم هست — با تابع `dict` و آرگومان‌های کلیدی:

```python
point = dict(x=1, y=2)
```

این راه دوم کوتاه‌تره چون نیازی به کوتیشن دور اسم کلیدها نیست — ولی فقط وقتی کار می‌کنه که کلیدها اسم متغیر معتبر باشن (نه هر رشته‌ی دلخواهی).

> نکته: کلیدهای دیکشنری باید از نوع **تغییرناپذیر** (immutable) باشن — معمولاً رشته یا عدد. مقدار می‌تونه هر نوعی باشه، هیچ محدودیتی نداره.

## خوندن و تغییردادن مقدار

```python
point = {"x": 1, "y": 2}

print(point["x"])
# 1

point["x"] = 10
point["z"] = 20

print(point)
# {'x': 10, 'y': 2, 'z': 20}
```

با کروشه، هم می‌شه مقدار یه کلید رو خوند، هم مقدار جدید بهش داد. اگه کلیدی که می‌نویسی از قبل وجود نداشته باشه، **کلید جدید اضافه می‌شه** (نه خطا).

## وقتی کلید وجود نداره

```python
point = {"x": 10, "y": 2}

print(point["a"])
# KeyError: 'a'
```

دو راه برای جلوگیری از این خطا:

```python
if "a" in point:
    print(point["a"])

print(point.get("a"))        # None if not found
print(point.get("a", 0))     # 0 if not found (your own default)
```

`get()` هیچ‌وقت خطا نمی‌ده — اگه کلید پیدا نشه، `None` (یا مقدار پیش‌فرضی که خودت بدی) برمی‌گردونه.

## حذف یه کلید

```python
del point["x"]
```

## پیمایش روی دیکشنری

```python
point = {"y": 2, "z": 20}

for key in point:
    print(key, point[key])
```

خروجی:
```
y 2
z 20
```

پیمایش ساده روی خود دیکشنری، فقط **کلیدها** رو می‌ده. اگه هم کلید هم مقدار رو می‌خوای، از `items()` استفاده کن:

```python
for key, value in point.items():
    print(key, value)
```

`items()` توی هر تکرار یه تاپل `(کلید, مقدار)` می‌ده، که مستقیم توی خود `for` بازش می‌کنیم — همون کاری که با `enumerate` روی لیست‌ها می‌کردیم.
