## یه لیست فقط‌خواندنی

**تاپل** (tuple) شبیه لیسته — یه دنباله از مقادیر — با یه فرق اساسی: **تغییرناپذیره** (immutable). نمی‌شه بهش عضو اضافه کرد، ازش حذف کرد، یا یه عضوش رو عوض کرد.

## ساخت تاپل

```python
point = (1, 2)
print(type(point))
# <class 'tuple'>
```

به‌جای کروشه، از پرانتز استفاده می‌کنیم. در واقع پرانتز هم لازم نیست — پایتون با دیدن کاما، خودش می‌فهمه داری تاپل می‌سازی:

```python
point = 1, 2
print(type(point))
# <class 'tuple'>
```

## نکته‌ی مهم: تاپل تک‌عضوی

```python
point = (1)
print(type(point))
# <class 'int'>   -- not a tuple!

point = (1,)
print(type(point))
# <class 'tuple'>   -- the comma is what matters
```

اگه بخوای یه تاپل با فقط یه عضو بسازی، باید یه کامای اضافه بعدش بذاری — وگرنه پایتون فکر می‌کنه پرانتز فقط برای گروه‌بندیه، نه تعریف تاپل. تاپل خالی هم با پرانتز خالی ساخته می‌شه: `()`.

## عملیات‌های آشنا

خیلی از کارهایی که با لیست می‌کردی، روی تاپل هم کار می‌کنه:

```python
a = (1, 2)
b = (3, 4)

print(a + b)         # (1, 2, 3, 4)  -- concatenation
print(a * 2)         # (1, 2, 1, 2)  -- repetition
print(tuple([1, 2])) # (1, 2)         -- from a list
print(tuple("ab"))   # ('a', 'b')     -- from a string

point = (1, 2, 3)
print(point[0])      # 1        -- indexing
print(point[0:2])     # (1, 2)   -- slicing
print(2 in point)     # True     -- membership check

x, y, z = point       # unpacking
```

## چیزی که نمی‌تونی بکنی

```python
point = (1, 2, 3)
point[0] = 100
# TypeError: 'tuple' object does not support item assignment
```

برای همین دلیل، تاپل متدهای `append`/`remove`/`insert` هم نداره — چون اصلاً قرار نیست تغییر کنه.

## کِی از تاپل استفاده کنیم

قانون کلی: وقتی یه دنباله از مقادیر داری که **نباید عوض بشه** — نه اضافه، نه کم، نه تغییر — از تاپل استفاده کن به‌جای لیست. این کار جلوی تغییرات سهوی رو می‌گیره؛ اگه یکی به‌اشتباه بخواد یه عضوش رو عوض کنه، پایتون همون لحظه با خطا جلوش رو می‌گیره.
