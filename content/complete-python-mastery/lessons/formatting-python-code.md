## PEP 8

اسناد رسمی پایتون **PEP** (مخفف Python Enhancement Proposal) نام دارند. مهم‌ترینشان برای نوشتن کد روزمره **PEP 8** است — راهنمای سبک نوشتن کد پایتون. رعایت PEP 8 باعث می‌شود کدت با کد بقیه‌ی برنامه‌نویس‌های پایتون هم‌شکل باشد.

مثلاً طبق PEP 8، دور عملگر انتساب `=` باید فاصله بگذاری:

```python
x = 1        # correct
x=1          # wrong
```

## فرمت‌بندی خودکار

لازم نیست همه‌ی قوانین PEP 8 را حفظ کنی — یک فرمتر خودکار (مثل **autopep8**) این کار را برایت انجام می‌دهد. در VS Code، از Command Palette دستور «Format Document» را اجرا کن.

فرمتر همچنین عادتِ تراز کردن دستیِ چند انتساب زیر هم را هم اصلاح می‌کند:

```python
x           = 1
y           = 2
unit_price  = 3
```

به این تبدیل می‌شود:

```python
x = 1
y = 2
unit_price = 3
```

## فرمت‌بندی خودکار موقع ذخیره

به‌جای اجرای دستی Format Document هر بار، از تنظیمات VS Code گزینه‌ی «Format On Save» را فعال کن تا با هر ذخیره‌ی فایل (Cmd/Ctrl+S)، کد خودکار فرمت شود.
