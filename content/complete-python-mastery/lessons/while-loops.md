## حلقه‌ی دوم: `while`

`for` رو برای پیمایش روی چیزهای پیمایش‌پذیر (range، رشته، لیست) استفاده می‌کنیم. ولی گاهی می‌خوایم یه کار رو **تا وقتی یه شرط برقراره** تکرار کنیم — نه بر اساس یه لیست مشخص. اونجاست که از `while` استفاده می‌کنیم:

```python
number = 100

while number > 0:
    print(number)
    number //= 2
```

خروجی:
```
100
50
25
12
6
3
1
```

بعد از `while`، یه شرط میاد (دقیقاً مثل `if`) — تا وقتی این شرط `True`ه، بدنه‌ی حلقه تکرار می‌شه. اینجا هر بار `number` رو نصف می‌کنیم (`//=` یعنی تقسیم صحیح و ذخیره‌ی نتیجه، مخفف `number = number // 2`) تا از ۰ کمتر بشه.

## یه مثال واقعی‌تر: گرفتن ورودی تا دستور خروج

یه الگوی خیلی رایج: از کاربر مدام ورودی بگیر، تا وقتی یه کلمه‌ی خاص (مثلاً `"quit"`) تایپ کنه:

```python
command = ""

while command != "quit":
    command = input("> ")
    print("echo:", command)
```

هر بار کاربر یه چیزی تایپ می‌کنه، همونو echo می‌کنیم. وقتی `quit` رو تایپ کنه، شرط `command != "quit"` دیگه `True` نیست، پس حلقه تموم می‌شه.

> نکته: چرا اولش `command` رو خالی گذاشتیم؟ چون پایتون قبل از اجرای حلقه باید بدونه `command` چیه تا بتونه شرط رو چک کنه — اگه اصلاً تعریفش نکرده بودیم، با خطا مواجه می‌شدیم.

## مراقب بزرگی/کوچیکی حروف باش

اگه کاربر به‌جای `quit`، بنویسه `Quit` یا `QUIT`، چی می‌شه؟

```python
command = ""

while command != "quit":
    command = input("> ")
```

چون مقایسه‌ی رشته‌ها به بزرگی/کوچیکی حروف حساسه، `"QUIT" != "quit"` هست، پس حلقه متوقف نمی‌شه! یه راه‌حل ضعیف اینه که همه‌ی حالت‌ها رو دستی چک کنی:

```python
while command != "quit" and command != "QUIT" and command != "Quit":
```

ولی این هیچ‌وقت همه‌ی حالت‌ها رو پوشش نمی‌ده (`qUiT` چی؟). راه‌حل درست، استفاده از متد `lower()` روی رشته‌ست تا هرچی کاربر تایپ کرد رو یکدست کوچیک کنیم:

```python
command = ""

while command.lower() != "quit":
    command = input("> ")
```

حالا فرقی نمی‌کنه کاربر چطور تایپ کنه — `quit`، `Quit`، `QUIT`، همه یکسان مدیریت می‌شن.
