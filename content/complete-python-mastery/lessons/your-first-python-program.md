## ساخت پروژه

داخل VS Code از File → Open یک پوشه‌ی خالی (مثلاً `hello-world`) باز کن. از پنل Explorer یک فایل جدید بساز و اسمش را `app.py` بگذار — همه‌ی فایل‌های پایتون پسوند `.py` دارند.

## تابع print

پایتون تعداد زیادی **تابع درونی (built-in function)** دارد؛ مثل دکمه‌های کنترل تلویزیون که هرکدام یک کار مشخص انجام می‌دهند. یکی از این توابع `print` است که چیزی را روی صفحه نمایش می‌دهد. برای **فراخوانی (call)** هر تابع، بعد از اسمش پرانتز باز و بسته می‌گذاری:

```python
print("Hello, World!")
```

متن همیشه داخل کوتیشن (تکی یا دوتایی) نوشته می‌شود.

## اجرای برنامه

VS Code یک ترمینال داخلی دارد (کلید میان‌بر: `` Ctrl+` ``). داخل ترمینال:

- ویندوز: `python app.py`
- مک/لینوکس: `python3 app.py`

```
$ python3 app.py
Hello, World!
```

## یک مثال دیگر: ضرب رشته

```python
print("Hello, World!")
print("*" * 10)
```

خروجی:

```
Hello, World!
**********
```

دستورهای برنامه دقیقاً از بالا به پایین و به‌ترتیب اجرا می‌شوند.
