## مقداردهی اولیه به یه آبجکت

می‌خوایم موقع ساختن یه `Point`، مقدار x و y رو بدیم:

```python
point = Point(1, 2)
```

برای این کار، به یه **سازنده** (constructor) نیاز داریم — یه متد خاص که پایتون خودش، موقع ساختن آبجکت، صداش می‌زنه.

## تعریف سازنده

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def draw(self):
        print(f"Point ({self.x}, {self.y})")
```

اسم سازنده همیشه `__init__` ه — دو زیرخط قبل و بعدش. این یکی از **متدهای جادویی** (magic method) پایتونه؛ بعداً توی همین بخش با چندتای دیگه‌شون هم آشنا می‌شیم.

## `self` دقیقاً چیه؟

وقتی می‌نویسی `Point(1, 2)`، پایتون پشت‌صحنه یه آبجکت جدید می‌سازه و `self` رو به همون آبجکت اشاره می‌ده. هر آبجکتی هم **ویژگی** (attribute) داره هم **متد** — ویژگی‌ها داده‌ی مربوط به اون آبجکتن (مثل `x` و `y`)، متدها کارهایی هستن که می‌تونی روی اون آبجکت انجام بدی (مثل `draw`).

توی `__init__`، با `self.x = x` مقدار پارامتر `x` رو به‌عنوان یه **ویژگی** روی همون آبجکت ذخیره می‌کنیم. از این به بعد، هر کد دیگه‌ای که به `self` دسترسی داشته باشه (مثل متد `draw`)، می‌تونه به همین `self.x` هم دسترسی داشته باشه.

## استفاده از آبجکت

```python
point = Point(1, 2)
print(point.x)
# 1

point.draw()
# Point (1, 2)
```

نکته‌ی مهم: وقتی متد `draw` رو صدا می‌زنی، **خودت مقداری برای `self` نمی‌دی** — پایتون خودش، پشت‌صحنه، آبجکت `point` رو به‌عنوان `self` پاس می‌ده. پس هر بار که یه متد رو صدا می‌زنی، فقط پارامترهای بعد از `self` رو باید بدی.
