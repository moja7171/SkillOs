## یه راه دیگه برای همون کار

`map` و `filter` رو یاد گرفتی — خیلی رایجن توی برنامه‌نویس‌هایی که پیشینه‌ی برنامه‌نویسی تابعی دارن. ولی پایتون یه ابزار دیگه هم داره که (تا جایی که نویسنده‌ی این دوره می‌دونه) خیلی از زبان‌های دیگه ندارنش: **List Comprehension**.

## نحو کلی

```python
[expression for item in iterable]
```

شبیه یه حلقه‌ی `for` است، فقط جمع‌وجورتر. مثال — بازنویسی همون کاری که `map` قبلاً می‌کرد:

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]

prices = [item[1] for item in items]
print(prices)
# [10, 5, 15]
```

این دقیقاً همون خروجی نسخه‌ی `map` رو می‌ده، ولی بدون پرانتز و کاما و `lambda` اضافه — به نظر خیلی‌ها (از جمله نویسنده‌ی این دوره) خواناتره.

## اضافه‌کردن فیلتر

می‌تونی یه شرط هم به آخرش اضافه کنی — دقیقاً کاری که `filter` می‌کرد:

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]

filtered = [item for item in items if item[1] >= 10]
print(filtered)
# [('Product 1', 10), ('Product 3', 15)]
```

اینجا عبارت (چیزی که برمی‌گرده) خود `item`ه — یعنی هیچ تبدیلی روش انجام نمی‌شه، فقط فیلتر می‌شه.

## کدوم رو استفاده کنیم؟

در جامعه‌ی پایتون، روش رایج‌تر و توصیه‌شده برای map/filter کردن یه لیست، **list comprehension**ه — هم خواناتره هم کاراتر. با این حال، چون توی کدهای دیگران زیاد به `map`/`filter` برمی‌خوری، لازم بود باهاشون هم آشنا باشی. جمع‌بندی: هر سه راه (حلقه‌ی معمولی، map/filter، list comprehension) به یه نتیجه می‌رسن — ولی برای نوشتن کد تازه، list comprehension رو ترجیح بده.
