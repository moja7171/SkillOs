## چسبوندن رشته‌ها به هم

فرض کن دوتا متغیر داری، اسم کوچیک و فامیل، و می‌خوای هردو رو باهم چاپ کنی:

```python
first = "Mosh"
last = "Hamedani"
full = first + " " + last
print(full)   # Mosh Hamedani
```

این کار می‌کنه، ولی یه روش بهتر و جدیدتر هم هست.

## رشته‌ی فرمت‌شده (f-string)

قبل از رشته، یه `f` می‌ذاری (حرف کوچیک یا بزرگ، فرقی نداره)، و هرجا می‌خوای یه متغیر رو وسط متن بذاری، داخل آکولاد می‌نویسیش:

```python
full = f"{first} {last}"
print(full)   # Mosh Hamedani
```

فرقش با رشته‌ی معمولی اینه که این یه مقدار ثابت نیست — یه **عبارت** ـه که موقع اجرا محاسبه می‌شه. هرچی داخل آکولاد باشه، جاش با نتیجه‌ش عوض می‌شه.

## نکته‌ی باحال: داخل آکولاد هر عبارتی جواب می‌ده

فقط اسم متغیر نیست — هر عبارت معتبر پایتون رو می‌تونی داخل آکولاد بذاری:

```python
print(f"{len(first)}")     # 4
print(f"{2 + 2}")           # 4
```

خط اول طول رشته‌ی `first` رو می‌ده، خط دوم نتیجه‌ی یه حساب ساده رو. یعنی می‌تونی حتی یه تابع صدا بزنی یا یه حساب‌وکتاب انجام بدی، درست وسط رشته.
