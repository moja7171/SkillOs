## ورودی گرفتن از تابع

تابع `greet()` توی درس قبل هیچ ورودی نمی‌گرفت. ولی `print` که همیشه استفاده می‌کنی، یه ورودی می‌گیره. بیا `greet` رو طوری بازنویسی کنیم که اسم بگیره:

```python
def greet(first_name, last_name):
    print(f"Hi {first_name} {last_name}")


greet("Mosh", "Hamedani")
greet("John", "Smith")
```

خروجی:
```
Hi Mosh Hamedani
Hi John Smith
```

## پارامتر در مقابل آرگومان

دو تا اصطلاح هست که خیلی‌ها قاطیشون می‌کنن:

- **پارامتر** (parameter): چیزی که توی تعریف تابع می‌نویسی — اینجا `first_name` و `last_name`.
- **آرگومان** (argument): مقدار واقعی‌ای که موقع صدازدن تابع بهش می‌دی — اینجا `"Mosh"` و `"Hamedani"`.

یعنی پارامتر جای خالیه، آرگومان همون چیزیه که می‌ذاری توی اون جای خالی.

## همه‌ی پارامترها به‌طور پیش‌فرض اجباری‌ان

اگه یه آرگومان رو جا بندازی:

```python
greet("Mosh")
```

با خطا مواجه می‌شی:
```
TypeError: greet() missing 1 required positional argument: 'last_name'
```

یعنی هر پارامتری که تعریف کنی، باید موقع صدازدن تابع براش یه مقدار بدی — مگه اینکه صریحاً بهش بگی اختیاریه (که توی یه درس بعدی می‌بینیمش).
