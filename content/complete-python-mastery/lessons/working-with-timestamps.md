## دو ماژول برای کار با تاریخ و زمان

پایتون دو ماژول اصلی برای کار با زمان داره: `time` که یه **timestamp** (مهر زمانی) می‌ده، و `datetime` که آبجکت‌های تاریخ/زمان با ویژگی‌هایی مثل سال و ماه می‌ده. توی این درس با `time` شروع می‌کنیم.

## `time.time()`: زمان فعلی به‌شکل یه عدد

```python
from time import time

print(time())
# 1700000000.123456
```

این عدد اعشاری، تعداد **ثانیه از یه نقطه‌ی ثابت شروع** (به اون می‌گیم epoch) رو نشون می‌ده — روی سیستم‌های یونیکسی، این نقطه اول ژانویه‌ی ۱۹۷۰ه. به این می‌گیم **Unix Epoch Time**.

این عدد خودش برای انسان قابل‌خوندن نیست، ولی برای **محاسبات** خیلی مفیده.

## کاربرد: اندازه‌گیری مدت‌زمان اجرا

```python
from time import time


def send_emails():
    for i in range(10000):
        pass


start = time()
send_emails()
end = time()

duration = end - start
print(duration)
```

با گرفتن `time()` قبل و بعد از اجرای یه تابع، و کم‌کردنشون از هم، مدت‌زمان اجرا (به ثانیه) رو به‌دست میاریم.

## یه راه دیگه: `timeit`

قبلاً توی این دوره با ماژول `timeit` هم آشنا شدیم که دقیقاً همین کار رو انجام می‌ده — اندازه‌گیری زمان اجرا. هر دو روش کاملاً معتبرن؛ همون‌طور که بیشتر یاد می‌گیری، می‌بینی که برای خیلی از مسائل، چند راه‌حل مختلف وجود داره.

## جمع‌بندی

`time.time()` یه عدد (ثانیه از epoch) برمی‌گردونه که برای محاسبات (مثل اندازه‌گیری مدت‌زمان) کاربردیه، ولی خودش قابل‌خوندن نیست. برای تاریخ/زمان قابل‌خوندن با ویژگی‌هایی مثل سال و ماه، سراغ ماژول `datetime` می‌ریم — موضوع درس بعدی.
