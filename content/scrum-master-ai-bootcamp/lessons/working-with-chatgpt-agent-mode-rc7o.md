## Agent Mode با دستیار معمولی چه فرقی داره

تا این‌جا با ChatGPT فقط **گفت‌وگو** کردیم — سؤال می‌پرسیدیم، متن یا فایل می‌گرفتیم. **Agent Mode** یه قدم جلوتره: به‌جای فقط جواب دادن، مدل می‌تونه واقعاً **اقدام** کنه — یه ترمینال باز کنه، کد بنویسه و اجراش کنه، وارد وبسایت بشه، یا به حساب‌های متصل (مثل تقویم) سر بزنه. یعنی از «فقط حرف زدن» به «واقعاً کاری انجام دادن» می‌ره.

## مثال ۱: افزودن ستون محاسبه‌شده به یه فایل اکسل

یه فایل بک‌لاگ اسپرینت داریم با ستون‌هایی مثل شناسه، عنوان، امتیاز داستان، MoSCoW، وضعیت. می‌خوایم دو تا ستون جدید اضافه بشه:

- **کل ساعت:** با فرض این‌که هر امتیاز داستان معادل ۸ ساعته، امتیاز ضربدر ۸.
- **ساعت باقی‌مونده:** کل ساعت منهای زمان صرف‌شده (که از قبل توی فایل هست).

فایل رو پیوست می‌کنیم و دستور رو می‌دیم. Agent Mode برای این کار یه محیط اجرایی باز می‌کنه، احتمالاً یه اسکریپت پایتون می‌نویسه، محاسبات رو اجرا می‌کنه، و فایل نهایی رو برمی‌گردونه — با ستون‌های محاسبه‌شده‌ی درست.

## مثال ۲: ساخت ارائه از یه سند

سند «چشم‌انداز و اهداف محصول» رو پیوست می‌کنیم و می‌خوایم یه فایل PPT حرفه‌ای ازش بسازه. Agent Mode این کار رو انجام می‌ده و یه فایل قابل‌دانلود تحویل می‌ده.

نتیجه قابل‌قبوله، ولی نکته‌ی مهمی که از این مثال یاد می‌گیریم: Agent Mode برای این کار **کند**تر از ابزارهای تخصصی مثل `Gamma.app` عمل می‌کنه و طراحی نهایی هم معمولاً ساده‌تره. یعنی این‌که یه ابزار **بتونه** کاری رو انجام بده، به این معنی نیست که **بهترین** ابزار برای اون کاره — برای ساخت ارائه، ابزار تخصصی هنوز برنده‌ست.

## مثال ۳: خوندن تقویم Outlook

با یه دستور ساده («جلسات هفته‌ی آینده‌ام رو از تقویم Outlook پیدا کن»)، Agent Mode می‌تونه وارد حساب متصل بشه و اطلاعات واقعی رو بیرون بکشه — مثلاً یه جلسه‌ی تکرارشونده‌ی روزانه یا یه تماس مرور هفتگی.

> نکته‌ی مهم: حتی وقتی Agent Mode اطلاعات واقعی رو درست می‌کشه بیرون، ممکنه یه جزئیات رو **اشتباه تفسیر کنه** — مثلاً اسم یه جلسه‌ی خاص رو با یه اصطلاح آشنا (مثل «lunch and learn») اشتباه بگیره، درحالی‌که اون اسم واقعی یه چیز کاملاً متفاوته. این دقیقاً همون درسی‌یه که توی چارچوب اعتبارسنجی AI یاد گرفتیم: هر خروجی، حتی وقتی از یه منبع واقعی میاد، باید بازبینی بشه.

> جمع‌بندی: Agent Mode برای کارهایی که نیاز به **اجرا** دارن (نه فقط تولید متن) مفیده — محاسبات روی فایل، خوندن حساب‌های متصل. ولی برای کارهایی که ابزار تخصصی‌شون بهتره (مثل ساخت ارائه)، همچنان بهتره سراغ همون ابزار تخصصی بری.
