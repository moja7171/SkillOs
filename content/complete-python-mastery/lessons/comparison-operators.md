## مقایسه‌ی مقادیر

عملگرهای مقایسه‌ای رو داری یه جا جمعشون کن:

```python
print(10 > 3)    # True
print(10 >= 3)   # True
print(10 < 20)   # True
print(10 <= 20)  # True
print(10 == 10)  # True
print(10 != 10)  # False
```

نتیجه‌ی هرکدوم یه مقدار بولیه: `True` یا `False`. به همچین عبارتی می‌گیم **عبارت بولی** (Boolean expression).

## وقتی نوع‌ها فرق دارن

```python
print(10 == "10")  # False!
```

با اینکه هر دو «ده» هستن، `False` می‌گیریم. چون یکی عدده و یکی رشته، و توی حافظه هم کاملاً متفاوت ذخیره می‌شن. پایتون قبل از هر مقایسه‌ای اول نوع‌ها رو چک می‌کنه؛ اگه فرق داشته باشن (و رابطه‌ی خاصی هم بینشون تعریف نشده باشه)، مساوی نیستن، تمام.

## مقایسه‌ی رشته‌ها

رشته‌ها هم قابل مقایسه‌ن — به ترتیب الفبایی:

```python
print("bag" > "apple")  # True
```

چون وقتی این دو کلمه رو مرتب کنی، `bag` بعد از `apple` میاد. اما این یکی جالب‌تره:

```python
print("bag" == "Bag")  # False
```

با اینکه فقط حرف اول بزرگه، مساوی نیستن! دلیلش اینه که هر کاراکتر یه نمایش عددی داره (توی خود پایتون با تابع `ord` می‌تونی ببینیش):

```python
print(ord("b"))  # 98
print(ord("B"))  # 66
```

چون `b` کوچیک و `B` بزرگ عدد متفاوتی دارن، `"bag"` و `"Bag"` هم رشته‌های متفاوتی حساب می‌شن. لازم نیست عددها رو حفظ کنی — فقط بدون که **مقایسه‌ی رشته‌ها حساس به بزرگی/کوچیکی حروفه**.

## جمع‌بندی

| عملگر | معنی |
|---|---|
| `==` | مساوی |
| `!=` | نامساوی |
| `>` `<` | بزرگ‌تر / کوچک‌تر |
| `>=` `<=` | بزرگ‌تر یا مساوی / کوچک‌تر یا مساوی |

نتیجه‌ی همه‌شون `True` یا `False`ست؛ بعدش با همین عبارت‌های بولی می‌ریم سراغ شرط‌ها.
