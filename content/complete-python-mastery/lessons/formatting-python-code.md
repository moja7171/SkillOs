## PEP 8 چیه؟

پایتون یه‌سری سند رسمی داره به اسم **PEP** (Python Enhancement Proposal). مهم‌ترینشون برای کد روزمره، **PEP 8** ـه — راهنمای سبک نوشتن کد پایتون. اگه رعایتش کنی، کدت با کد بقیه‌ی برنامه‌نویس‌های پایتون هم‌شکل می‌شه و راحت‌تر خونده می‌شه.

مثلاً طبق PEP 8، دور علامت `=` باید فاصله بذاری:

```python
x = 1        # correct
x=1          # wrong
```

## نگران حفظ‌کردنش نباش

خبر خوب: لازم نیست همه‌ی قوانین PEP 8 رو حفظ کنی. یه ابزار به اسم **autopep8** خودش کدت رو مرتب می‌کنه. توی VS Code از Command Palette دستور «Format Document» رو بزن، تمام.

حتی اگه عادت داری چندتا انتساب رو زیر هم تراز کنی:

```python
x           = 1
y           = 2
unit_price  = 3
```

فرمتر خودش درستش می‌کنه:

```python
x = 1
y = 2
unit_price = 3
```

## هر بار دستی نزن، خودکارش کن

به‌جای اینکه هر بار Format Document رو دستی بزنی، از تنظیمات VS Code گزینه‌ی «Format On Save» رو فعال کن — از این به بعد هر بار ذخیره می‌کنی (Cmd/Ctrl+S)، کدت خودکار مرتب می‌شه.
