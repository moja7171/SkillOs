## یه پروژه بساز

توی VS Code از File → Open یه پوشه‌ی خالی باز کن (مثلاً `hello-world`). از پنل Explorer یه فایل جدید بساز و اسمش رو بذار `app.py` — همه‌ی فایل‌های پایتون پسوند `.py` دارن.

## آشنایی با print

پایتون کلی **تابع درونی (built-in function)** داره که از قبل آماده‌ست و می‌تونی استفاده کنی. فکرش رو بکن مثل دکمه‌های کنترل تلویزیون — هرکدوم یه کار مشخص می‌کنن (روشن، خاموش، تغییر کانال). یکی از این توابع `print` ـه که یه چیزی رو روی صفحه نشون می‌ده:

```python
print("Hello, World!")
```

برای **صدا زدن (call)** هر تابعی، بعد از اسمش پرانتز باز و بسته می‌ذاری. متن هم همیشه باید داخل کوتیشن باشه (تکی یا دوتایی، فرقی نداره).

## بزن اجراش کن

VS Code یه ترمینال داخلی داره (میان‌بر: `` Ctrl+` ``). اونجا بنویس:

- ویندوز: `python app.py`
- مک/لینوکس: `python3 app.py`

```
$ python3 app.py
Hello, World!
```

## یه بازی کوچیک باهاش

```python
print("Hello, World!")
print("*" * 10)
```

نتیجه چی می‌شه؟

```
Hello, World!
**********
```

ضرب کردن یه رشته توی یه عدد، اون رشته رو همون تعداد بار تکرار می‌کنه. و یه نکته‌ی مهم: دستورهای برنامه دقیقاً از بالا به پایین، به همون ترتیبی که نوشتیشون، اجرا می‌شن.
