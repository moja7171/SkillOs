## چرا دیباگر؟

فرض کن این تابع رو داری:

```python
def multiply(*numbers):
    total = 1
    for number in numbers:
        total *= number
        return total   # bug: wrong indentation (same mistake as the args lesson)


print(multiply(1, 2, 3))
```

انتظار داری `6` بگیری، ولی `1` می‌گیری. می‌تونی با چشم دنبال باگ بگردی، ولی توی برنامه‌های بزرگ‌تر این کار سخت و وقت‌گیره. راه بهتر: **دیباگر** (debugger) — ابزاری که بهت اجازه می‌ده برنامه رو خط‌به‌خط اجرا کنی و ببینی توی هر لحظه چه مقداری توی هر متغیر ذخیره‌ست.

## راه‌اندازی اولیه

اولین بار که می‌خوای دیباگ کنی، از پنل Debug روی آیکن مربوطه کلیک کن — یه فایل `launch.json` توی پوشه‌ی `.vscode` ساخته می‌شه. لازم نیست چیزی توش دستکاری کنی. از لیست کانفیگ‌ها، **Python: Current File with Integrated Terminal** رو انتخاب کن (کانفیگ‌های دیگه برای پروژه‌های پیچیده‌تری مثل Django هستن).

## گذاشتن Breakpoint

روی خطی که می‌خوای اجرا اونجا متوقف بشه، کلیک کن (مثلاً همون خط `print(multiply(...))`)، بعد `F9` رو بزن. یه نقطه‌ی قرمز کنار اون خط ظاهر می‌شه — این همون **breakpoint**ه. با زدن دوباره‌ی `F9` می‌تونی حذفش کنی.

## اجرا و قدم‌زدن

| کلید | کار |
|---|---|
| `F5` | اجرا کن تا اولین breakpoint |
| `F10` | یه خط جلو برو (Step Over) — اگه اون خط یه تابع صدا بزنه، بدون رفتن داخلش رد می‌شه |
| `F11` | برو **داخل** تابعی که این خط صداش می‌زنه (Step Into) |
| `Shift + F11` | از تابع فعلی بیا **بیرون** (Step Out) — وقتی می‌دونی بقیه‌ی اون تابع درسته و نمی‌خوای خط‌به‌خط ردش کنی |
| `Shift + F5` | دیباگ رو کامل متوقف کن |

با `F5` برنامه تا اولین breakpoint اجرا می‌شه. با `F10` یه خط جلو می‌ری. وقتی به خطی می‌رسی که تابع `multiply` رو صدا می‌زنه، به‌جای `F10` از `F11` استفاده کن تا **بری داخل خود تابع**.

## دنبال‌کردن متغیرها

توی پنل سمت چپ (Variables → Locals)، مقدار همه‌ی متغیرهای محلی همون لحظه رو می‌بینی. با `F10` قدم‌به‌قدم جلو برو و ببین `total` و `number` توی هر تکرار چی می‌شن — دقیقاً همون‌جاست که متوجه می‌شی چرا `return` زودتر از موقع اجرا شده و حلقه ناقص می‌مونه.

## نکته‌ی کاربردی

لازم نیست همیشه breakpoint رو روی اولین خط برنامه بذاری. اگه از قبل می‌دونی مشکل توی یه تابع خاصه، breakpoint رو مستقیم اول همون تابع بذار — با `F5` دقیقاً همون‌جا شروع می‌کنی، بدون رد شدن از خط‌های قبلش.
