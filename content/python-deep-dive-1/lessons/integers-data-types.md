## پنج نوع عدد در پایتون

ریاضیات چهار مجموعه‌ی تودرتو دارد و پایتون برای هر کدام نوعی دارد:

| مجموعه | مثال | نوع پایتون |
|---|---|---|
| اعداد صحیح ℤ | 0, ±1, ±2, … | `int` |
| اعداد گویا ℚ (کسر دو عدد صحیح، مخرج غیر صفر) | 22/7 | `fractions.Fraction` |
| اعداد حقیقی ℝ | 0.125, π, e | `float` (پیش‌فرض) یا `decimal.Decimal` (وقتی دقت را می‌خواهی کنترل کنی) |
| اعداد مختلط ℂ (a + bi) | 3 + 4j | `complex` |

ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ. پایتون یک نوع پنجم هم به این خانواده اضافه می‌کند: **`bool`** — چون `False` همان `0` و `True` همان `1` است. (π/3 گویا نیست؛ کسر باید از دو عدد *صحیح* باشد.)

## int چقدر می‌تواند بزرگ شود؟

کامپیوتر همه‌چیز را در **مبنای ۲** نگه می‌دارد. عدد `10011₂` یعنی `1·16 + 0·8 + 0·4 + 1·2 + 1·1 = 19` — نمایش ۱۹ پنج بیت لازم دارد.

با ۸ بیت، بزرگ‌ترین عدد نامنفی `2⁸ − 1 = 255` است. اگر علامت هم بخواهیم، یک بیت خرج علامت می‌شود و می‌ماند ۷ بیت: بازه‌ی `−128` تا `127` (چون صفر علامت ندارد، یک عدد اضافه به سمت منفی می‌رسد). قاعده‌ی کلی برای n بیت علامت‌دار: `−2ⁿ⁻¹` تا `2ⁿ⁻¹ − 1`. با ۱۶ بیت: `±32,768`، با ۳۲ بیت: حدود `±2.1 میلیارد`.

نکته‌ی جانبی مدرس: به همین دلیل یک سیستم‌عامل ۳۲ بیتی نمی‌تواند بیش از ۴ گیگابایت حافظه آدرس‌دهی کند — آدرس‌ها خودشان عدد صحیح ۳۲ بیتی‌اند: `2³²` آدرس × ۱ بایت = ۴ GB.

زبان‌هایی مثل Java و C انواع **عرض ثابت** دارند و باید از قبل تصمیم بگیری: `byte` (۸ بیت)، `short` (۱۶)، `int` (۳۲)، `long` (۶۴)، گاهی signed/unsigned. **پایتون این‌طور نیست.** `int` یک شیء با تعداد بیت **متغیر** است: هر چه عدد بزرگ‌تر شود، پایتون بی‌سروصدا بیت بیشتری برایش می‌گیرد — ۳۲، ۶۴، ۹۶، … . حد بالا فقط حافظه‌ی در دسترس است.

## هزینه‌اش

```python
import sys
sys.getsizeof(0)        # 24  ← سربار خود شیء
sys.getsizeof(1)        # 28  ← ۴ بایت برای خود عدد
sys.getsizeof(2**1000)  # 160 ← (160-24)*8 = 1088 بیت
```

و سرعت: جمع دو عدد ۳۲/۶۴ بیتی یک عمل CPU است؛ اعداد بزرگ‌تر باید تکه‌تکه پردازش شوند. benchmark مدرس (۱۰ میلیون بار `n * 2`): با `10` ≈ ۰٫۵ ثانیه، با `2**100` ≈ ۰٫۹ ثانیه، با `2**10000` ≈ ۶٫۷ ثانیه.

```python
import time

def calc(a):
    for i in range(10_000_000):
        a * 2

start = time.perf_counter()
calc(2 ** 10000)
print(time.perf_counter() - start)
```

جمع‌بندی: عدد صحیح دلخواه‌بزرگ کاملاً شفاف کار می‌کند؛ فقط بدان که حافظه‌ی بیشتر می‌خورد و عملیات رویش کندتر می‌شود.
