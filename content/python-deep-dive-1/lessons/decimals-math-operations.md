## `//` و `%` روی Decimal فرق دارند

معادله‌ی همیشگی هنوز برقرار است: `n == d * (n // d) + (n % d)`. ولی برای int، `//` **floor division** است؛ برای Decimal، **truncated division**. برای اعداد مثبت یکی است، برای منفی‌ها نه:

```python
10 // 3, 10 % 3                            # (3, 1)
Decimal(10) // Decimal(3), Decimal(10) % Decimal(3)   # (Decimal('3'), Decimal('1'))

-10 // 3, -10 % 3                          # (-4, 2)   ← floor
Decimal(-10) // Decimal(3), Decimal(-10) % Decimal(3)  # (Decimal('-3'), Decimal('-1'))  ← trunc
```

الگوریتم Decimal: علامت نتیجه را حساب کن، قدر مطلق بگیر، تا وقتی `a >= b` مدام `b` را کم کن، تعداد کم‌کردن‌ها را با علامت برگردان. برای `−10 / 3`: علامت منفی؛ `10−3=7, 7−3=4, 4−3=1` → سه بار → `−3`. همان truncation `−3.33`. و چون `//` این‌طور تعریف شده، `%` باید طوری باشد که معادله بماند: `3 × (−3) + (−1) = −10` ✓.

مثال مدرس: `−135` و `4` → int: `(−34, 1)`؛ Decimal: `(−33, −3)`. هر دو معادله را برقرار می‌کنند. `divmod` هم به همین ترتیب.

(عملگرها polymorphic هستند: `//` روی دو Decimal، پیاده‌سازی خود کلاس Decimal را صدا می‌زند. سازوکارش — متدهای dunder — در بخش شی‌ءگرایی.)

## توابع ریاضی: متد روی خود شیء

Decimal خیلی از توابع ریاضی را دارد — به‌صورت **متد** نه تابع: `sqrt`, `exp`, `ln`, `log10`, `logb`, `max`, `min`, `copy_sign`, … ولی نه همه: **توابع مثلثاتی ندارد** (برای مالی معمولاً مهم نیست).

```python
a = Decimal('1.5')
a.ln(), a.exp(), a.sqrt()
```

## چرا از ماژول math استفاده نکنیم؟

می‌شود `math.sqrt(a)` را روی Decimal صدا زد، ولی `math` اول Decimal را به **float** تبدیل می‌کند و بعد عمل می‌کند — یعنی همه‌ی دقتی که برایش Decimal را انتخاب کردی از دست می‌رود:

```python
import math
x = 0.01
x_dec = Decimal('0.01')          # نه Decimal(0.01)!

root_float = math.sqrt(x)        # 0.1000000000000000055511151231257827
root_mixed = math.sqrt(x_dec)    # همان — تبدیل به float شد
root_dec = x_dec.sqrt()          # Decimal('0.1')  ← دقیق

root_float * root_float          # 0.010000000000000002
root_mixed * root_mixed          # همان
root_dec * root_dec              # Decimal('0.01')  ← برمی‌گردد
```

قاعده: با Decimal، متدهای خود Decimal؛ `math` را فقط وقتی به کار ببر که معادل Decimal وجود ندارد (و بدان که آنجا با float کار می‌کنی).

نکته‌ی جانبی که مدرس در کدنویسی به آن برخورد: اگر تصادفاً `Decimal(0.01)` (float) بسازی، همان اول دقیق نیستی — «از رشته بساز» را جدی بگیر.
