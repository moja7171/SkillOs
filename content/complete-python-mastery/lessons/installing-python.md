## دانلود و نصب

به [python.org](https://python.org) برو، از بخش Downloads آخرین نسخه‌ی پایتون را دانلود کن و نصب‌کننده را اجرا کن.

> در ویندوز، حتماً گزینه‌ی «Add Python to PATH» را در صفحه‌ی نصب تیک بزن؛ بدون آن نمی‌توانی پایتون را از خط فرمان اجرا کنی.

## بررسی نصب

بعد از نصب باید مطمئن شوی همه‌چیز درست کار می‌کند.

**ویندوز**: در نوار جست‌وجو `cmd` را تایپ کن تا Command Prompt باز شود، بعد بنویس:

```
python
```

**مک/لینوکس**: ترمینال را باز کن (روی مک: Command+Space و تایپ Terminal) و بنویس:

```
python3
```

> روی مک و لینوکس، دستور `python` معمولاً به پایتون ۲ (نسخه‌ی قدیمی) اشاره دارد؛ همیشه از `python3` استفاده کن.

اگر پیام نسخه را دیدی (مثلاً `Python 3.x.x`)، نصب موفق بوده است. برای خروج از این محیط تعاملی: در ویندوز `Ctrl+Z` و بعد Enter، و در مک/لینوکس `Ctrl+D`.
