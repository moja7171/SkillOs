## آرگومان موقعیتی: بر اساس ترتیب

```python
def my_func(a, b):
    ...

my_func(10, 20)    # a=10, b=20
my_func(20, 10)    # a=20, b=10
```

اولین آرگومان به اولین پارامتر، دومی به دومی.

## مقدار پیش‌فرض = آرگومان اختیاری

```python
def my_func(a, b=100):
    ...

my_func(10, 20)    # a=10, b=20
my_func(5)         # a=5,  b=100
```

**قانون:** وقتی به یک پارامتر موقعیتی مقدار پیش‌فرض دادی، **همه‌ی پارامترهای بعد از آن** هم باید مقدار پیش‌فرض داشته باشند. `def fn(a, b=2, c)` تعریف نمی‌شود — چون `fn(5, 25)` مبهم است: ۲۵ برای `b` یا `c`؟ (می‌توانی `c=None` بدهی؛ فقط باید چیزی بدهی.)

```python
def my_func(a, b=5, c=10):
    ...

my_func(1)         # 1, 5, 10
my_func(1, 2)      # 1, 2, 10
my_func(1, 2, 3)   # 1, 2, 3
my_func()          # TypeError — a پیش‌فرض ندارد
```

## آرگومان کلیدواژه‌ای (named)

می‌خواهی `a` و `c` را بدهی ولی `b` پیش‌فرض بماند؟ با موقعیت نمی‌شود. با **نام** می‌شود:

```python
my_func(a=1, c=2)     # 1, 5, 2
my_func(1, c=2)       # 1, 5, 2   — مخلوط: موقعیتی بعد نام‌دار
my_func(c=30, b=20, a=10)   # ترتیب نام‌دارها مهم نیست
```

نام باید دقیقاً نام پارامتر باشد. و این فقط برای پارامترهای پیش‌فرض‌دار نیست — حتی وقتی هیچ پیش‌فرضی نداری، نام‌دار مجاز است و **ترتیب را آزاد می‌کند** یا برای خوانایی به کار می‌رود:

```python
def my_func(a, b, c): ...
my_func(1, 2, c=3)
my_func(c=3, a=1, b=2)
```

## قانون دوم: بعد از نام‌دار، فقط نام‌دار

```python
my_func(c=1, 2, 3)      # SyntaxError
my_func(1, b=2, 3)      # SyntaxError
```

وقتی یکی را با نام دادی، ۲ و ۳ برای کدام پارامترند؟ مبهم است. پس: اول موقعیتی‌ها، بعد نام‌دارها؛ و بعد از اولین نام‌دار، همه نام‌دار. (شبیه قانون پیش‌فرض‌ها در تعریف: بعد از اولین پیش‌فرض، همه پیش‌فرض.)

پیش‌فرض‌ها همچنان قابل حذف‌اند: `my_func(a=1, b=5)` → `c` پیش‌فرض.
