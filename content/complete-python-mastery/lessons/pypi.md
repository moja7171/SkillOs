## وقتی کتابخانه‌ی استاندارد کافی نیست

کتابخانه‌ی استاندارد پایتون خیلی جامعه، ولی همه‌چیز رو نداره. هر وقت به یه قابلیتی نیاز داشتی که پایتون خودش آماده نداره (مثلاً کار با فایل‌های PDF)، احتمالاً یه نفر دیگه از قبل یه پکیج براش نوشته و منتشر کرده.

## PyPI: مخزن مرکزی پکیج‌های پایتون

**PyPI** (مخفف Python Package Index، سایت pypi.org) یه مخزن مرکزیه که صدها هزار پکیج شخص‌ثالث پایتون توش ثبت شدن — نوشته‌شده توسط برنامه‌نویس‌های مختلف، نه خود تیم پایتون. مفهومش شبیه npm برای جاوااسکریپته: هر کسی می‌تونه پکیج خودش رو اونجا منتشر کنه، و هر کسی می‌تونه پکیج‌های دیگران رو نصب و استفاده کنه.

اگه دنبال یه قابلیت خاص بگردی (مثلاً «کار با PDF»)، معمولاً چند صد یا چند هزار پکیج مرتبط پیدا می‌کنی — بعضی‌هاشون خوب و پایدار، بعضی‌ها ناقص یا رهاشده. برای انتخاب یه پکیج خوب، می‌شه به تعداد دانلود، تاریخ آخرین به‌روزرسانی، و نظر جامعه (مثلاً با جست‌وجوی «بهترین پکیج پایتون برای X») توجه کرد.

## چی توی این بخش می‌بینیم

توی این بخش یاد می‌گیریم چطور این پکیج‌ها رو نصب کنیم، محیط پروژه‌هامون رو از هم جدا نگه داریم، و حتی چطور پکیج خودمون رو منتشر کنیم.
