## وب API

وب API خیلی شبیه اپ وبه، با دو فرق مهم: یک، صفحه‌ی HTML سرو نمی‌کنه، بلکه داده سرو می‌کنه — معمولاً به شکل ساختار JSON. دو، کلاینت‌هاش مرورگرهای وب نیستن، بلکه اپلیکیشن‌های دیگه‌ان — از جمله کد JavaScript‌ای که داخل مرورگر اجرا می‌شه.

وب API توی چند سال اخیر خیلی محبوب شده و تقریباً هر اپ وبی، علاوه بر خود اپ، یه وب API هم ارائه می‌ده. وب API، همون‌طور که از اسمش پیداست، یه رابط برنامه‌نویسی اپلیکیشن (API) رو در معرض دید می‌ذاره که به برنامه‌های دیگه اجازه می‌ده بهش دسترسی داشته باشن و کارهای مختلفی رو اجرا کنن.

انواع مختلفی از پیاده‌سازی وب API وجود داره، ولی محبوب‌ترینش با فاصله‌ی زیاد، **REST API**‌ـه. REST یه موضوع خیلی گسترده با کلی فلسفه و تفکر پشتشه، ولی برای این دوره کافیه بدونیم REST به ما اجازه می‌ده به موجودیت‌ها با ترکیبی از URL، پارامترها و فعل HTTP دسترسی داشته باشیم. مثلاً یه URL خاص می‌تونه یعنی «کاربر شماره‌ی ۱۷ رو بهم بده»، و یه URL دیگه می‌تونه یعنی «سفارش شماره‌ی ۱۵۶ رو حذف کن».

همون‌طور که می‌بینی، مزیت اصلی REST اینه که چیزی بیشتر از یه URL استاندارد برای اجرای API لازم نداره، و برخلاف پروتکل‌های سنگینی مثل SOAP، به پروتکل‌های اضافیِ روی HTTP نیازی نداره.

### کِی از وب API استفاده کنیم؟

وب API‌ها برای دریافت و ذخیره‌ی داده استفاده می‌شن — نه برای برگردوندن نشانه‌گذاریِ بصری مثل HTML. به همین دلیل، تقریباً هر نوع اپلیکیشنی می‌تونه کلاینت یه وب API باشه — هر کدی که بتونه به REST API دسترسی داشته باشه، و تقریباً هر زبانی این قابلیت رو داره. به همین خاطره که وب API‌ها هم توسط اپ‌های وب استفاده می‌شن، هم اپلیکیشن‌های rich client و هم سیستم‌های دیگه.

اپلیکیشن‌های وب API بهترین گزینه‌ان برای:

- سیستم‌هایی که به دریافت و ذخیره‌ی داده نیاز دارن، هرچند نه حجم زیادی از داده توی هر اکشن.
- اکشن‌هایی که کلاینت شروعشون می‌کنه — یعنی فراخوانی‌کننده درخواست انجام یه کار رو می‌ده، مثل گرفتن همه‌ی داده‌ها یا ذخیره‌ی نام کاربری.
- مقیاس بزرگ با تعداد زیاد کاربر و داده‌ی زیاد.
- اکشن‌های کوتاه و متمرکز، نه فرایندهای طولانی‌مدت.

وب API و اپ وب روی همون مفهوم ساخته شدن و معمولاً زیرساخت مشترکی دارن. پس مثل اپ وب، وب API هم توی مدل درخواست-پاسخ بهترین عملکرد رو داره و باید برای همین نوع سیستم‌ها استفاده بشه. فرایندهای طولانی‌مدت باید موقع استفاده از وب API کنار گذاشته بشن.
