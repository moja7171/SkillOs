## یه مرور سریع

قبلاً یه متد جادویی (magic method) دیدیم: `__init__`. متدهای جادویی متدهایی هستن که اسمشون با دو زیرخط شروع و تموم می‌شه، و **خودت مستقیم صداشون نمی‌زنی** — پایتون بسته به اینکه چطور از آبجکتت استفاده می‌کنی، خودش خودکار صداشون می‌زنه. پایتون کلی متد جادویی داره؛ توی این بخش با مهم‌ترین‌هاشون آشنا می‌شیم.

## `__str__`: نمایش متنی یه آبجکت

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y


point = Point(1, 2)
print(point)
```

خروجی پیش‌فرض چیزی شبیه اینه:
```
<__main__.Point object at 0x7f8a1c0b5d90>
```

نه خیلی مفید — فقط اسم کلاس و آدرس حافظه‌ی آبجکت. پایتون این خروجی رو از یه متد جادویی به اسم `__str__` می‌گیره که `Point` از یه کلاس والد (بعداً توی همین بخش، «وراثت» رو می‌بینیم) به ارث برده. می‌تونیم خودمون بازنویسیش کنیم:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"


point = Point(1, 2)
print(point)
# (1, 2)
```

هر وقت پایتون بخواد یه آبجکت رو به رشته تبدیل کنه — چه با `print`، چه با تابع `str()` — همین متد صدا زده می‌شه:

```python
print(str(point))
# (1, 2)
```

## یه فهرست کامل

پایتون دسته‌های مختلفی از متد جادویی داره — برای نمایش آبجکت (مثل `__str__`)، برای مقایسه، برای عملیات ریاضی، و خیلی موارد دیگه. توی درس‌های بعدی، مهم‌ترین‌هاشون رو یکی‌یکی می‌بینیم.
