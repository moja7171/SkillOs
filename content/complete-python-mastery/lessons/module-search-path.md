## وقتی `import sales` می‌نویسیم، پایتون کجا می‌گرده؟

توی `app.py` وقتی می‌نویسیم:

```python
import sales
```

پایتون باید بفهمه فایل `sales.py` کجاست. این جست‌وجو به یه ترتیب مشخص انجام می‌شه.

## `sys.path`: لیست مکان‌های جست‌وجو

ماژول آماده‌ی `sys` یه متغیر به اسم `path` داره که لیست پوشه‌هایی که پایتون توشون دنبال ماژول می‌گرده رو نشون می‌ده:

```python
import sys

print(sys.path)
```

خروجی یه لیست از رشته‌هاست، مثلاً:

```
['/home/user/projects/python-course', '/usr/lib/python3.11', ...]
```

## ترتیب جست‌وجو

1. **اول پوشه‌ی فعلی** — همون پوشه‌ای که فایل درحال‌اجرا توشه.
2. **بعد پوشه‌های نصب پایتون** — جایی که کتابخانه‌ها و ماژول‌های استاندارد نصب شدن (روی مک و لینوکس یه مسیر شبیه `/usr/lib/pythonX.Y`، روی ویندوز یه چیزی شبیه `C:\Program Files\Python...`).

پایتون این پوشه‌ها رو **به‌ترتیب** می‌گرده و همین‌که فایل رو پیدا کنه، جست‌وجو متوقف می‌شه.

## اگه توی زیرپوشه باشه چی؟

اگه یه ماژول توی یه زیرپوشه باشه (نه توی پوشه‌ی فعلی مستقیم)، این لیست به‌تنهایی کافی نیست — باید مفهوم **پکیج** رو بشناسیم، که موضوع درس بعدیه.
