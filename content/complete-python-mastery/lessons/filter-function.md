## نگه‌داشتن فقط اعضایی که یه شرط رو دارن

همون لیست سفارش‌ها: فرض کن فقط سفارش‌هایی رو می‌خوای که قیمتشون ۱۰ دلار یا بیشتره.

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]
```

راه پایه:

```python
filtered = []
for item in items:
    if item[1] >= 10:
        filtered.append(item)
```

## راه کوتاه‌تر: تابع `filter`

```python
items = [("Product 1", 10), ("Product 2", 5), ("Product 3", 15)]

x = filter(lambda item: item[1] >= 10, items)
filtered = list(x)

print(filtered)
# [('Product 1', 10), ('Product 3', 15)]
```

`filter(تابع, پیمایش‌پذیر)` هم شبیه `map` عمل می‌کنه — تابعی که بهش می‌دی باید یه **مقدار بولی** برگردونه (True/False). فقط اعضایی که تابع براشون `True` برگردوند، توی نتیجه می‌مونن؛ بقیه کنار گذاشته می‌شن.

## فرق `map` با `filter`

- `map`: تعداد اعضا همون می‌مونه، فقط **شکلشون** عوض می‌شه.
- `filter`: شکل اعضا همون می‌مونه، فقط **تعدادشون** کم می‌شه (بعضی حذف می‌شن).

هر دو، مثل `sort`، یه شیء پیمایش‌پذیر (نه لیست مستقیم) برمی‌گردونن — برای گرفتن لیست واقعی، دورشون `list()` بذار.
