## مفسر پایتون

محیطی که با نوشتن `python` یا `python3` باز می‌شود، **مفسر پایتون (Python interpreter)** است — برنامه‌ای که کد پایتون را اجرا می‌کند. کد را می‌توانی داخل یک فایل بنویسی و به مفسر بدهی، یا مستقیم داخل همین محیط تعاملی (interactive shell) تایپ کنی.

## عبارت (Expression)

در برنامه‌نویسی، **عبارت (expression)** تکه‌کدی است که یک مقدار تولید می‌کند:

```python
>>> 2 + 2
4
```

مقایسه هم یک نوع عبارت است؛ نتیجه‌اش یک مقدار **بولی (Boolean)** یعنی `True` یا `False`:

```python
>>> 2 > 1
True
>>> 2 > 5
False
```

## خطای نحوی (Syntax Error)

اگر عبارت را ناقص بنویسی:

```python
>>> 2 >
```

مفسر خطای **syntax error** می‌دهد. Syntax یعنی گرامر یا دستور زبان؛ همان‌طور که یک جمله‌ی بی‌گرامر در زبان فارسی قابل‌فهم نیست، کد بی‌گرامر هم برای مفسر پایتون قابل‌فهم نیست.

> محیط تعاملی برای امتحان سریع یک تکه‌کد عالی است، ولی برای ساختن برنامه‌های واقعی به یک ویرایشگر کد نیاز داری — موضوع درس بعدی.
