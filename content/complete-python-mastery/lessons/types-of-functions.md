## دو نوع تابع

توی برنامه‌نویسی، دو نوع تابع داریم:

1. تابعی که یه **کار انجام می‌ده** — مثل `print` یا همون `greet` که توی درس‌های قبل نوشتیم. فقط یه کاری می‌کنه (چاپ‌کردن)، ولی مقداری برنمی‌گردونه که بشه ذخیره‌ش کرد.
2. تابعی که یه چیزی **محاسبه و برمی‌گردونه** — مثل `round`.

## بازنویسی `greet` به شکل دوم

```python
def get_greeting(name):
    return f"Hi {name}"


message = get_greeting("Mosh")
print(message)
```

خروجی:
```
Hi Mosh
```

به‌جای اینکه مستقیم چاپ کنیم، با `return` مقدار رو برمی‌گردونیم. چون یه مقدار برگردونده می‌شه، می‌تونیم توی یه متغیر (`message`) ذخیره‌ش کنیم.

## چرا این شکل بهتره؟

با نسخه‌ی اول (`print` توی خود تابع)، همیشه قفل شدیم به چاپ‌کردن توی ترمینال. اگه بعداً بخوایم همون پیام رو توی یه فایل بنویسیم یا توی یه ایمیل بفرستیم، باید یه تابع دیگه بسازیم. ولی نسخه‌ی دوم فقط یه مقدار برمی‌گردونه — بعدش خودمون تصمیم می‌گیریم باهاش چی‌کار کنیم: چاپش کنیم، توی فایل بنویسیمش، یا هر کار دیگه.

## مقدار پیش‌فرض: `None`

```python
def greet(name):
    print(f"Hi {name}")


result = greet("Mosh")
print(result)
```

خروجی:
```
Hi Mosh
None
```

وقتی تابعی صریحاً `return` نداره، به‌طور پیش‌فرض `None` برمی‌گردونه — `None` یعنی «نبود مقدار». پس **هر تابعی توی پایتون یه چیزی برمی‌گردونه**، حتی اگه خودت صریحاً ننویسیش؛ فقط اگه ننویسی، اون چیز `None`ه. با این حال، همچنان جزو دسته‌ی اول (توابع «انجام‌دهنده‌ی کار») حساب می‌شه، چون هدفش برگردوندن یه مقدار معنادار نیست.
