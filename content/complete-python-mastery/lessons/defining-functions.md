## چرا خودمون تابع بسازیم؟

تا الان از تابع‌های آماده‌ی پایتون مثل `print` و `round` استفاده کردی. وقتی یه برنامه‌ی واقعی می‌نویسی، صدها یا هزاران خط کد داری — نباید همه‌شو توی یه فایل، پشت‌سرهم بریزی. باید کدت رو به تکه‌های کوچیک‌تر، قابل‌نگهداری‌تر و قابل‌استفاده‌ی دوباره تقسیم کنی. به این تکه‌ها می‌گیم **تابع** (function).

## ساخت یه تابع

```python
def greet():
    print("Hi there")
    print("Welcome aboard")


greet()
```

خروجی:
```
Hi there
Welcome aboard
```

قدم‌به‌قدم:
- با `def` شروع می‌کنیم (مخفف define).
- بعدش اسم تابع — همون قانون‌های نام‌گذاری متغیرها اینجا هم صدق می‌کنه: حروف کوچیک، واضح و توصیفی، کلمات جدا با `_`.
- بعد از اسم، یه پرانتز باز و بسته، بعد `:`.
- خط‌های زیرش با تورفتگی، بدنه‌ی تابع رو تشکیل می‌دن.

بعد از تعریف تابع، دو خط خالی می‌ذاریم (این چیزیه که PEP8 پیشنهاد می‌ده) — اگه یادت رفت، به‌محض ذخیره‌کردن، AutoPep8 خودش اضافه‌ش می‌کنه.

## صدا زدن تابع

فقط تعریف‌کردن یه تابع، اجراش نمی‌کنه. برای اجراش، باید **صداش بزنی** (call)، دقیقاً مثل تابع‌های آماده: اسمش رو بنویس، بعدش پرانتز باز و بسته: `greet()`.
